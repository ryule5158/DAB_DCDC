## 1. 本轮最终冻结内容

1. 只保留输入定制共模电感 `LCM1=2mH/绕组、30A`，不设置输入旁路铜桥。
2. 输出端不使用共模电感，不保留其封装或相关旁路铜桥。
3. 输出功率链固定为 `副边全桥 -> CSEC -> LOUT 2.2uH -> COUT -> FOUT -> 输出分流器 -> DTVS_CONN -> JOUT`。
4. 八只 AONS66917 均采用 `0/10.18V` 驱动，不使用负压。
5. 每管固定 `Rg_on=4.7Ohm`、`Rg_off=2.2Ohm`、`Dg=PMEG4010ER`、`Rgs=10kOhm`、`Zgs=BZT52C15`。
6. 完全不使用有源加速关断器件，也不保留相关 DNP 焊盘。
7. 所有驱动返回线从 MOS Source 焊盘分叉，独立返回 UCC21520 的 VSSA/VSSB。

## 2. 模型中实际完成的电路修改

八个 `Qx_DRV_EQ` 子系统全部统一为：

```text
Gate command 0/10V -> GateScale 1.018 -> GateBias 0V
                    -> ideal rail command 0/10.18V

turn-on:
rail -> UCC source impedance 1.15Ohm -> Rg_on 4.7Ohm -> Gate

turn-off:
Gate -> Rg_off 2.2Ohm -> PMEG4010ER -> UCC sink impedance 0.55Ohm -> rail

Gate -> Rgs 10kOhm -> local Source
Gate -> BZT52C15 cathode; BZT52C15 anode -> local Source
```

UCC21520 数据手册给出低态输出阻抗约 `0.55Ohm`。高态5Ohm是静态P沟道器件数据，转换期间另有约1.47Ohm的N沟道增强支路；两者并联约1.14Ohm，因此模型采用 `1.15Ohm` 的动态拉高近似。该近似比完全理想电压源保守且更接近实际转换过程。

PMEG4010ER 使用 `Vf=0.30V + 0.19Ohm*I` 的分段线性近似，使1A附近压降约0.49V。15V齐纳作为真实反向击穿支路跨接Gate-Source。

## 7. PCB必须照做的门极回路

- UCC21520输出到Gate与Source返回必须成对紧靠走线。
- Source独立返回线必须从MOS Source焊盘处分叉，不能从远处PGND或开关铜皮取回。
- `Rg_on/Rg_off/Dg/Rgs/Zgs` 均放在MOS焊盘旁，目标距离2-3mm。
- PMEG4010ER阳极朝Gate/Rg_off侧，阴极朝UCC输出侧。
- BZT52C15阴极接Gate、阳极接Source独立回线。
- Vgs测试点直接跨Gate与该Source分叉点；高侧必须使用合适共模范围的差分探头。
- 不画任何有源加速关断焊盘。
