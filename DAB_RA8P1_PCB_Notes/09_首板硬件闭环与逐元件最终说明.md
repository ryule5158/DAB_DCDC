# 首板硬件闭环与逐元件最终说明

版本：H1.2  
日期：2026-07-11  
用途：第一次画 300W 级高频隔离功率板时，作为原理图逐网照画、PCB 摆放和送板前复核的最终说明。

## 1. 最终结论与绝对约束

变压器和共模电感已经购买并定制完成，以下参数永久锁定：

- T1：PQ4040 / PC95，3:6 匝，Np:Ns=1:2，原边 Lm=57.5µH，副边 Lm=230µH。
- T1：副边折算总传输漏感标称 0.50µH，模型按 ±20% 核算。
- LCM1：每绕组 2mH、30A、DCR≤3.5mΩ，12 匝、2.3mm 线。

任何后续问题都不得用重绕、改匝数、改 Lm、改漏感标称或更换共模电感来掩盖。实测偏差只允许缩小工作域和功率。

完成本轮 P0 修正后，器件电压等级、驱动电源、快速关断、输出储能短路保护和 PCB 分区已经形成可画首版原理图的硬件基线。但在以下三项完成前，仍不能把它称为已经实物验证：

1. RA8P1 比赛开发板准确型号、连接器与 GPT/ADC/POEG 实际引脚冻结。
2. 最终原理图逐网 ERC 和第二人复核。
3. 首板按 04 文档完成低压、分功率、双脉冲和热平衡测试。

## 2. 固定磁件后的工作电压

300W 连续不是任意组合的矩形范围，而是二维准入区：

~~~text
18V ≤ Vin ≤ 28V
36V ≤ Vout ≤ 48V
|Vout - 2Vin| ≤ 8V
~~~

进入普通 SPS 前使用更严格的 7.5V 边界，连续保持边界为 8V。逐伏对应关系：

| Vin | 允许 Vout |
|---:|---:|
| 18V | 36–44V |
| 19V | 36–46V |
| 20–22V | 36–48V |
| 23V | 38–48V |
| 24V | 40–48V |
| 25V | 42–48V |
| 26V | 44–48V |
| 27V | 46–48V |
| 28V | 48V |
| 29–32V | 只允许测量和保护上电；禁止普通 SPS 开桥 |

500W 只允许在 21–24V、|Vout-2Vin|≤4V 内做 1s、3s、5s 分级短时实验。若比赛必须声明一个任意组合的矩形 300W 范围，只能声明 Vin=20–22V、Vout=36–48V。

## 3. 最终整机电气顺序

### 3.1 主功率输入

~~~text
JIN → F1 50A BF1/MIDI → DTVS_IN SMCJ33A
    → LCM1 已购共模电感
    → CIN1–4 / CIN_HF1–10 / CIN_FILM
    → ZBUS_PRI SMCJ33A → 原边全桥 → T1 已购变压器
~~~

- DTVS_IN 处理连接器和线缆侧浪涌，必须在 F1 后、LCM1 前。
- ZBUS_PRI 是另一颗独立 TVS，放在 LCM1 后、原边桥局部 MLCC 旁。
- 两颗 TVS 位置不同、作用不同，不能只画一颗然后在 PCB 上拉长线。
- RBLEED_IN1–4 为四只 20kΩ/0.5W 并联，总 5kΩ，跨 LCM1 后的输入电容星点。

### 3.2 辅助隔离电源支路

~~~text
F1 后输入 → F_AUX 1.5A/63V 慢断 → TPS26600PWP
          → 100µF/63V + 1µF/63V + 100nF/100V
          → URH2405LP-20WR3 → 5V_CTRL / DGND_CTRL
~~~

URH2405 工作输入 9–36V、最大输入 40V、1s 浪涌 50V，而 SMCJ33A 最大钳位约 53V。因此必须用 TPS26600 在约 35.4V 切断，不能只靠 TVS。

认证边界必须单独写清：URH2405 数据手册给出 5kVAC 隔离耐压，但厂家产品页当前明确提示 2024-05-01 之后的 UL 认证无效。竞赛首板可以按电气隔离样机使用该器件和兼容封装位，但 BOM、论文和铭牌均不得宣称它当前具备有效 UL 认证。未来若做认证产品，必须替换为认证状态明确的等效模块并重新审查整机隔离。

TPS26600 连接锁定：

| 引脚/外围 | 连接 |
|---|---|
| IN | F_AUX 后 |
| OUT | URH 输入电容和 URH 正输入 |
| UVLO | 接 RTN，使用内部约 15V UVLO |
| OVP | 866kΩ/0.1% 到 IN，30.1kΩ/0.1% 到 RTN |
| ILIM | 8.00kΩ/1% 到 RTN，典型约 1.5A |
| dVdT | 47nF 到 RTN，32V 下约 12ms 斜坡 |
| MODE | 悬空，断路器自动重试 |
| SHDN | 按数据手册留空并留测试点，不接高压 VIN |
| FLT | 只留 PRI_POWER 测试点，不接控制岛 |
| RTN/GND | 按 TI 推荐网络分开，禁止直接短接 |

TPS26600 和 URH 输入侧都属于 PRI_POWER。只有 URH 输出之后才是 CTRL_ISLAND。

### 3.3 副边局部母线和输出

~~~text
副边全桥 → CSEC1–2 + CSEC_HF1–8 + ZBUS_SEC
         → LOUT 2.2µH
         → COUT_HF1–8 + COUT1–8 + RBLEED_OUT + VOUT采样/OVP
         → FOUT PV-15A10-2P → RSHUNT_OUT1–2 → JOUT
~~~

另一颗 DTVS_CONN=SMCJ48A 放在 FOUT 后、JOUT 旁边。

- CSEC1–2：2×EEUFS2A470，47µF/100V，并联后 94µF、最大阻抗约 56mΩ；负责桥前中频储能和阻尼。
- CSEC_HF1–8：8×C5750X7S2A106K230KE；每个副边半桥 4 只，全部在 LOUT 前，负责 300kHz 换流。
- ZBUS_SEC：SMCJ48A，直接跨副边桥局部母线并贴 CSEC_HF。
- LOUT：SER2915H-222KL，只是输出后级 2.2µH 滤波电感，不是 DAB 的 0.50µH 传输漏感。
- COUT_HF1–8：另 8×同型号 MLCC，全部在 LOUT 后；与 CSEC_HF 不能合并。
- COUT1–8：8×1000µF/80V，最终总 8000µF；首上电先装 4 只。
- RBLEED_OUT1–2：2×2.49kΩ/1W 串联，总 4.98kΩ；48V 到 5V 约 90s。
- FOUT：PV-15A10-2P，15A、1000VDC、50kA 分断，切断输出电容对外部硬短路的放电。
- DTVS_CONN：只负责输出线缆/接口浪涌；其短路失效由 FOUT 隔离。

VOUT 电压采样、VOUT 硬件过压和泄放电阻都必须接在 LOUT 后、FOUT 前的 COUT 星点。这样即使 FOUT 断开，本地 8mF 电容仍能被监测和泄放。

## 4. 四块完全相同的驱动板

一块驱动板只驱动一个半桥。四块板原理图和 PCB 完全相同，只改丝印地址。

### 4.1 控制侧失效安全逻辑

UDIS=SN74LVC1G10，三输入 NAND：

~~~text
A = RUN_REQ
B = FAULT_LATCH_N
C = ESTOP_N
Y = UCC21520 DIS
~~~

只有三路全为高时 DIS 才为低、PWM 才可通过。每块板必须有：

- PWM_H、PWM_L 各 10kΩ 下拉。
- RUN_REQ 10kΩ 下拉。
- FAULT_LATCH_N 47kΩ 下拉。
- ESTOP_N 47kΩ 下拉。
- DIS 10kΩ 上拉到 3V3_DRV。
- UDIS 独立 100nF 去耦。

因此 MCU 复位、连接器断线、故障线悬空或逻辑器件漏焊都会趋向 DIS=高。

### 4.2 UCC33421 隔离 5V

| 器件 | 最终值 | 连接要求 |
|---|---:|---|
| UISO | UCC33421QDHARQ1 | VINP/GNDP 属于 CTRL_ISLAND；VCC/GNDS 属于本半桥功率侧 |
| 输入第一去耦 | 15nF/50V | 直接跨 VINP–GNDP |
| 输入储能 | 10µF/10V | 紧随 15nF |
| 输出第一去耦 | 15nF/50V | 直接跨 VCC–GNDS |
| 输出储能 | 22µF/10V | 同网只允许这一颗 22µF |
| EN/FLT 上拉 | 22kΩ/1% | 上拉到 5V_CTRL；故障节点回主板 PWRFLT |
| SEL | 0Ω接隔离侧 VCC | 明确选择 5.0V，不得悬空 |

原先再加一颗 22µF 的 TLV 输入电容会使同网达到约 44µF，可能触发 UCC33421 的 16ms 启动超时，已从主线删除。

### 4.3 TLV61046 升压到 10.18V

TLV61046 的反馈典型基准约 0.795V：

~~~text
VOUT = 0.795 × (1 + 118k/10k) ≈ 10.18V
~~~

旧 71.5kΩ/10kΩ 只能得到约 6.48V，低于 UCC21520 约 8V UVLO，绝对不能继续照画。

| 器件 | 最终值/连接 |
|---|---|
| LBOOST | 15µH SDR0302-150ML |
| TLV 输入本地 | 1µF/10V + 100nF，UCC 的 22µF 同时承担共享储能 |
| EN 上拉 | 隔离 5V → 100kΩ → EN |
| EN 下拉 | EN → 100kΩ → GNDS |
| EN 延时 | EN → 220nF → GNDS |
| EN 快放 | 1N4148W 阳极接 EN、阴极接隔离 5V |
| 反馈 | 118kΩ/0.1% 从 VOUT 到 FB；10.0kΩ/0.1% 从 FB 到 GNDS |
| TLV 输出本地 | 2.2µF/25V + 100nF |
| UCC21520 VDDB | 4.7µF/25V + 100nF |
| 自举 | 1µF/25V + 100nF，位于二极管后 |

TLV 输出与 VDDB 同网名义总电容约 7.1µF。上电后 MCU 至少等待 30ms，并确认未出现驱动电源故障，才能拉高 RUN_REQ。

按 Qg 最大 115nC、Vg=10.18V、300kHz，两只 MOS 门极功率约 0.70W；加驱动静态损耗、按 80% 升压效率，UCC33421 输出负担接近 0.99W。因此 UISO 板温≤85°C 才允许连续；95°C 必须降频/降功率；105°C 硬停机。

### 4.4 门极终端器件必须在主板

以下器件属于主功率板 MOS 侧终端，不随可拔驱动板离开：

- Rg_on=4.7Ω。
- Rg_off=2.2Ω，预留 1.0/1.5/1.8/2.7Ω。
- Dg=PMEG4010ER。
- Rgs=10kΩ。
- Zgs=BZT52C15，阴极接 G、阳极接 Kelvin S。

Rgs/Zgs 直接跨 MOS G–Kelvin S，距焊盘目标 2–3mm。Vgs 测试点放在门极电阻之后。

驱动板功率接口应命名为高侧 OUTA、SH_KELVIN×2，低侧 OUTB、SL_KELVIN×2。不再把已经过门极电阻的 GH/GL 当作小板输出。接口插合高度≤5mm，完整门极环路目标<10mm、上限 15mm。

## 5. 硬件故障链

### 5.1 总体路径

~~~text
IPRI_OC_N / ISEC_OC_N / VIN_OV_N / VOUT_OV_N
PWRFLT1-4 / ESTOP_N
              ↓
        RAW_FAULT_N → RA8P1 POEG
                    → SN74LVC1G74 /PRE
SN74LVC1G74 /Q = FAULT_LATCH_N
FAULT_LATCH_N → 四块驱动板 NAND → UCC21520 DIS
~~~

软件只记录原因、保持 RUN 低并在安全后请求复位，不参与第一拍关断。

### 5.2 两路 TMCS1133 过流

- IPRI_OC_N、ISEC_OC_N 各自用 4.7kΩ上拉到 3V3_AFE，保留独立 MCU 诊断。
- 每路通过 BAT54H 汇入 RAW_FAULT_N：阳极接 RAW_FAULT_N，阴极接对应 OC_N。
- 原边 VOC 门限约 65.3A，副边约 40.0A；它们是最后硬件门限，不是连续目标。
- 不允许提高门限来扩大固定磁件工作域。

### 5.3 驱动电源故障汇总

主板 U_FAULT_OD=SN74LVC07APWR，3V3_DRV 供电：

- CH1–CH4 输入 PWRFLT1–4；每个输入主板侧 100kΩ 下拉，检测小板脱插。
- CH1–CH4 开漏输出并成 AUX_PG_N。
- AUX_PG_N 用 2.2kΩ 上拉到 3V3_DRV，并送 RA8P1 独立诊断。
- CH5 输入 AUX_PG_N，输出接 RAW_FAULT_N。
- CH6 输入 ESTOP_N，输出接 RAW_FAULT_N。

SN74LVC07A 输入容忍 5V，可读取 UCC33421 EN/FLT；四路 EN/FLT 不直接并联，也不再用 BAT54 作为主线。

### 5.4 急停

~~~text
3V3_DRV → 1kΩ → J_ESTOP-1 → 外部常闭干接点
J_ESTOP-2 = ESTOP_SENSE
ESTOP_SENSE → 10kΩ → DGND_CTRL
ESTOP_SENSE → 1nF → DGND_CTRL
ESTOP_SENSE → SN74LVC1G17 → ESTOP_N
~~~

断线、脱插和按下急停都会得到低电平。ESTOP_N 同时直达四块驱动板和故障汇总，不能只送 MCU。

### 5.5 锁存和复位

SN74LVC1G74 的 /PRE=RAW_FAULT_N，/CLR=FAULT_RESET_N，D/CLK 接 DGND_CTRL，Q=FAULT_LATCHED，/Q=FAULT_LATCH_N。

FAULT_RESET_N 用 10kΩ 上拉到 3V3_DRV；RA8P1 只能用开漏输出，经 1kΩ 接 /CLR。建议复位低脉冲 20µs，且只在 RUN_REQ=0、RAW_FAULT_N=1、电压电流温度恢复安全后发出。禁止用 RC 上电自动清故障。

### 5.6 硬件过压精确值

TLV3202 两路都采用 ADC 信号进 IN−、阈值进 IN+，原始推挽输出正常高、过压低，再由 SN74LVC2G07 开漏汇入 RAW_FAULT_N。

- VIN：3V3_AFE→7.68kΩ→VIN_THR；VIN_THR→10.0kΩ→AGND；原始比较器输出→1MΩ→VIN_THR。理论跳闸 34.26V、释放 34.00V。
- VOUT：VBIAS_1V65→4.99kΩ→VOUT_THR；原始比较器输出→1MΩ→VOUT_THR。理论跳闸 52.01V、释放 51.49V。

4.99kΩ 不能省。若把低阻 1.65V 直接接 IN+，1MΩ 正反馈几乎不起迟滞作用。

## 6. 检测板和 RA8P1 接口取舍

为隔离、精度和快速保护，TMCS1133、CSS2H 分流器、AMC3302 高压侧、AMC3330 高压侧分压器和 TLV3202 与主功率板一体，不做可拔原始检测小板。只有隔离后的低压信号进入 CTRL_ISLAND；禁止把分流器毫伏信号经排针拉远。

比赛提供的是 RA8P1 开发板，因此使用独立转接板：

- 主功率板冻结 JCTRL_DIG、JCTRL_ANA、JCOMM 网络名。
- 转接板按比赛开发板实际连接器映射 GPT A/B、ADC、POEG、UART/CAN。
- 四个半桥必须来自四组硬件 GPT 互补输出，不能退化成软件 GPIO 翻转。
- RAW_FAULT_N 必须进入可直接关断 GPT 的 POEG。
- RA8P1 USB 地只属于 CTRL_ISLAND。

## 7. 300mm × 150mm 四层 PCB 的具体摆放

从左到右：

1. 0–60mm：JIN、F1、DTVS_IN、LCM1、辅助 eFuse/URH 输入。
2. 60–125mm：CIN、ZBUS_PRI、原边两半桥、原边 TMCS。
3. 125–175mm：T1、原副边纵向隔离槽、传输漏感 0Ω 调试铜排。
4. 175–235mm：副边 TMCS、副边两半桥、CSEC/CSEC_HF/ZBUS_SEC。
5. 235–300mm：LOUT、COUT 阵列、FOUT、输出分流器、DTVS_CONN、JOUT。

从下到上：0–35mm 为 CTRL_ISLAND，35–45mm 为连续无铜隔离带，45–150mm 为功率区。在 x≈150mm 再做原副边 8mm 全层无铜纵向隔离带，T1 跨越该边界。

| 层 | 用途 |
|---|---|
| L1 外层 2oz，优先 3oz | MOS、局部 MLCC、门极终端、传感器和最短换流回路 |
| L2 1oz | 每个电气岛自己的连续参考面；局部 DC+ 与 PGND 相邻重叠 |
| L3 1oz | 低阻母线、5V/3V3 分配；三域严格切断 |
| L4 外层 2oz，优先 3oz | 大电流加固、热扩散、铜排与低速控制 |

PCB 必须先摆八只 MOS、本地 MLCC、八组门极终端、四块低矮驱动接口、T1、TMCS、CSEC_HF、LOUT 和三条隔离槽，最后才摆大电解与控制接口。

关键制造规则：

- 任何 20A 以上路径不得出现小于 3–5mm 的细铜颈。
- 大电流焊盘禁用热焊盘。
- 换层过孔阵列横跨整个电流宽度。
- 开关节点只做到承载电流所需面积，不从 FB、ADC、EN 延时、比较器阈值或 Kelvin 线下方穿过。
- SER2915H 约 29.7g，除焊盘外用中性硅胶或机械压片固定。
- FOUT 靠板边和风道，远离电解。
- PRI_POWER、SEC_POWER、CTRL_ISLAND 之间所有层均保持≥8mm 无铜；隔离器和 T1 下开 1–2mm 槽。
- 靠隔离带的安装孔优先尼龙螺柱；金属孔周围所有层至少 3–4mm 无铜。

## 8. 与 TI TIDA-010954 的相同点和差异

可以借鉴其高频变压器隔离和漏感传能、局部换流电容、短环路、Kelvin 回路、UCC33421、TMCS1133、硬件先关断以及分阶段测试方法。SPS、EPS、死区补偿、ZVS 和循环电流的思想也互通。

不能照搬：

| TI 参考设计 | 本项目 |
|---|---|
| 600W DC-AC 单相周波变换器 | 300W 连续、500W短时 DC-DC DAB |
| 交流侧半桥周波开关 | 副边完整有源全桥 |
| 650V GaN 功率级 | 100V 离散硅 MOSFET |
| C2000 controlCARD | 比赛 RA8P1 开发板和独立转接板 |
| 电网 PLL、PR、极性切换、THD | 输出直流电压/电流闭环和双向功率管理 |
| 27–60V 到 230VAC | 固定 1:2 磁件下的 18–28V 到 36–48V 二维工作域 |

TI 第 27 页的 7V/10A、50V 负载测试是低压开环实验方法，不代表本项目能在 7V→50V 运行；可借鉴的是限流、从零相移逐步增加和逐级验证。

## 9. 送板前最后检查

### 电气

- 磁件参数与已购实物一致，没有被任何文档或模型改写。
- TLV 反馈是 118kΩ/10.0kΩ，不再出现 71.5kΩ/10kΩ。
- UCC 输出只有一颗 22µF；10V_GATE 直连总电容名义值约 7.1µF。
- 每个故障允许信号断线都使 DIS=高。
- RAW_FAULT_N 到 POEG 和锁存不经过 MCU 软件。
- VOUT 采样/OVP/泄放在 FOUT 前；DTVS_CONN 在 FOUT 后。
- CSEC_HF 与 COUT_HF 各有 8 只。
- ZBUS_PRI、ZBUS_SEC、DTVS_IN、DTVS_CONN 四颗 TVS 均存在且位置正确。
- TPS26600 的 RTN/GND 没有错误短接，FLT 没跨隔离带。

### PCB

- 八个 Rg_on/Rg_off/Dg/Rgs/Zgs 都在主板 MOS 旁。
- 驱动板功率接口没有普通长排针。
- 四个半桥局部 MLCC 都在换流回路内。
- 三域隔离槽在所有层都无铜。
- 输入 40A 瞬时路径和输出 15A 路径无细颈、热焊盘和单过孔瓶颈。
- F1、FOUT、JIN、JOUT 的机械力不传到电容或细铜。

### 启动

- 上电默认 RUN_REQ=0。
- 驱动隔离 5V 先建立，BOOST_EN 约 6–9ms 后开启，10V_GATE 在约 30ms 内一次建立到 9.9–10.5V。
- 不出现约 160ms 周期打嗝。
- Vout<36V 时禁止普通 50% 方波 SPS；使用受限 EPS/PDM/三电平窄脉冲，或仅为稳态测试做外部预充。

完整工作域见 08；采购和位号以 26 为准；上电顺序以 04 为准。
