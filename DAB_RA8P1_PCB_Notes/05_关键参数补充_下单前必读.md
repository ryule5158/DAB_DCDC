# 关键参数补充：下单前必读

本页对 01 和 26 中需要在建立器件库时进一步锁定的细节作补充；发生冲突时以本页为准。

## 1. PQ4040 磁芯的准确料号

首选磁芯锁定为 TDK PC95PQ40/40Z-12：

- 生产状态。
- Ae=201mm²。
- 有效磁路长度 102mm。
- 未开气隙 AL=6400nH/N²，容差 ±25%。

因此未开气隙时：

- Np=3 匝，Lp≈6400nH×3²=57.6µH。
- Ns=6 匝，Ls≈6400nH×6²=230.4µH。

这与模型的 57.5µH/230µH 以及 1:2 匝比直接对应。当前变压器已经定制完成，匝数、气隙、Lm 和漏感都不得再改，也不再提出重绕或筛选要求。来料只做 Lm、短路漏感、DCR、耐压、匝间电容和温升实测；实测偏差只能用于缩小 08 文档的工作域和降额，不能反向改磁件或提高过流门限。

## 2. 四块 UCC33421 的 EN/FLT 汇总

每块 EN/FLT 用 22kΩ/1% 上拉到 5V_CTRL，故障时该引脚会拉低约 200µs。22kΩ 避免 18kΩ/1% 的负公差落到数据手册要求的 18kΩ 下方；SEL 明确接隔离侧 VCC。四个引脚不得直接硬并联。

主板使用一颗 SN74LVC07APWR：四个 PWRFLT 输入各用 100kΩ 下拉检测小板脱插，CH1–CH4 开漏输出并成 AUX_PG_N，AUX_PG_N 用 2.2kΩ 上拉到 3V3_DRV；CH5 再把 AUX_PG_N 拉入 RAW_FAULT_N，CH6 处理 ESTOP_N。SN74LVC07A 的输入可接受 5V，输出只接 3.3V 开漏总线。BAT54 汇总只留 DNP，不作为定版主线。

## 3. 3.3V 模拟与驱动逻辑分支

TLV77333 输出定义为 3V3_AFE，供 AMC、TMCS、TLV6004、REF2033 和比较器。

从 3V3_AFE 经一颗 600Ω@100MHz 的磁珠和 4.7µF+100nF，得到 3V3_DRV，供四块 UCC21520 的 VCCI 与 SN74LVC1G10。驱动板控制连接器原先标注的 3V3_AFE 在正式原理图中改名为 3V3_DRV。

这样避免 8 路 PWM 输入电流直接污染精密模拟电源，同时两者仍属于同一个 CTRL_ISLAND。

## 4. MLCC 容量口径

TDK C5750 系列具有官方直流偏压模型，但数据手册的名义容量不能直接当作 32V 或 48V 下的有效容量。

- 输入 10×22µF/100V 是器件数量起点，布局再预留至少 2–6 个同封装 DNP 焊盘。
- 副边桥前 CSEC_HF1–8 与 LOUT 后 COUT_HF1–8 是两组独立的 8×10µF/100V 软端头，不能合并。两组都以 48V 偏压下取得约 40µF 以上实测有效容量为目标。
- 建板前用 TDK 官方 DC Bias 模型再次读出 32V/48V、25°C 和高温有效值。
- 实板通过小信号阻抗或阶跃响应反算总有效容量；不以丝印上的 80µF/220µF 作为验收值。

## 5. 驱动保护时间的口径

TMCS1133 OC 响应在 120% 阈值时典型约 100ns、最大约 250ns；UCC21520 输入到输出关断传播最大约 45ns，再加锁存/逻辑和实际栅极下降时间，首板设计目标约 0.35µs，不把它宣传为 40ns 或 100ns 整机保护。

## 6. TMCS1133 统一料号修正

U_IPRI 和 U_ISEC 都锁定为 TMCS1133B7AQDVGR，不再采购 B8A。B7A 在 3.3V 下灵敏度 20mV/A、双向线性范围约 ±77.5A。

- 原边 VOC：10.0kΩ 上臂、1.91kΩ 下臂，计入约 120kΩ 输入阻抗后约 0.522V，对应约 65.3A。
- 次级 VOC：9.24kΩ 上臂、1.00kΩ 下臂，计入约 120kΩ 输入阻抗后约 0.320V，对应约 40.0A。

次级 40A 时 VOUT 约为 0.85V 或 2.45V，ADC 余量仍充分。统一料号的主要原因是 B7A 有授权渠道现货，而 B8A 供应风险较高。

## 7. 下单前的供应链门槛

- 先锁定 8 只同批次 AONS66917、4 只 UCC21520DWR、2 只 TMCS1133B7AQDVGR、4 只 UCC33421QDHARQ1，再发正式 Gerber。
- UCC33421QDHARQ1 是当前驱动板的强化隔离核心，不能把功能绝缘小模块静默替换进去；若交期延后，只暂停驱动小板投板，主功率板接口不变。
- 每块驱动板预留“外部隔离 5V 测试输入 + 焊接选择跳线”，仅用于实验室单板验证；正常整机必须由板载 UCC33421 供电，禁止把四个浮置输出并联。
- 采购记录必须保存制造商完整型号、日期码和授权渠道，不用仅按关键词相似的市场替代品。

## 8. UCC33421 热降额与驱动板位置

UCC33421 的 1.5W 额定只适用于环境温度不高于 85°C；105°C 时为 1W，125°C 时为 0.5W。AONS66917 最大 Qg、10.18V、300kHz 下每半桥门极功率约 0.70W，加 UCC21520 静态损耗后 TLV 输出约 0.79W；按保守 80% 升压效率折算，UCC33421 隔离输出负担接近 0.99W，在 105°C 已几乎没有余量。

因此四块小板低矮平放在半桥侧边，不能盖住 MOS 或位于热风出口；UCC33421 朝冷风入口。设计状态机使用 85°C 连续目标、95°C 降功率、105°C 硬停机。这个温度是驱动板 UISO 附近局部环境/板温，不是等到芯片内部热关断才处理。

## 9. 辅助输入过压切断

URH2405LP-20WR3 的工作输入为 9–36V、最大输入 40V、1s 浪涌 50V；SMCJ33A 的最大钳位约 53V，不能单独保证模块安全。F_AUX 后、URH 前增加 TPS26600PWP：

- UVLO 接 RTN，使用内部约 15V 欠压门槛。
- OVP 用 866kΩ/0.1% 与 30.1kΩ/0.1%，切断范围约 34.8–36.5V。
- ILIM 到 RTN 用 8.00kΩ/1%，典型限流约 1.5A。
- dVdT 到 RTN 用 47nF，32V 下约 12ms 斜坡。
- MODE 悬空为断路器自动重试；SHDN 按数据手册留空并设测试点。
- RTN 与 GND 不得直接短接，否则失去反接保护。

该支路只保护辅助模块，不改变主功率输入范围，也不跨接 CTRL_ISLAND 与 PRI_POWER。

## 10. 输出储能的独立保险

8mF 在 48V 储能约 9.22J。输入 F1、TMCS 和桥臂关断都不能切断这部分电容向外部短路放电，因此输出顺序固定为：

~~~text
LOUT → COUT_HF/COUT/RBLEED/VOUT_OV → PV-15A10-2P → 输出分流器 → JOUT
~~~

PV-15A10-2P 为 15A、1000VDC、50kA 分断的 gPV PCB 熔断器。300W/36V 连续约 8.3A；500W/36V 约 13.9A 只允许 1s、3s、5s 分级短时。保险用于外部线缆/接口硬短路，不能替代 MOS 的亚微秒硬件过流关断。
