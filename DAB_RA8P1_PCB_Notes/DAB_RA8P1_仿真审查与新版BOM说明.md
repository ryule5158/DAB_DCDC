# DAB RA8P1 仿真审查、优化与新版 BOM 说明

更新时间：2026-07-10  
适用模型：`DAB_RA8P1_Final_Physical_MOSFET.slx`  
MATLAB/Simulink：R2024b  
当前额定验证点：输入 `24V`，输出设定 `48V`，负载 `100W`  
短时高功率验证点：`24V -> 48V / 500W`

## 1. 先给结论

本轮没有改变固定的变压器匝比，也没有在反馈端增加隐藏增益。变压器仍为：

- 原边等效励磁电感：`57.5uH`
- 副边等效励磁电感：`230uH`
- 匝比：`Np:Ns = 1:2`
- 耦合系数：`0.999999`
- 副边折算传输漏感：`0.5uH`

本轮真正落实到电路层面的主要修改为：

1. 删除输出端两只错误建模的独立 `2.2uH` 串联“EMI 电感”。
2. 保留一只真实可采购的 `2.2uH` 输出功率电感。
3. 将输出大电容落实为 8 只可采购的 `1000uF/80V` 电解电容并联。
4. 将输出 MLCC 按 48V 直流偏压后的保守有效电容建模。
5. 将 8 只功率 MOSFET 从旧基线 `IPT015N10N5` 改为 `AONS66917`。
6. 为栅极驱动、隔离采样、硬件过流、TVS、保险丝和连接器给出具体选型。

最终保存模型在 `24V -> 48V / 100W` 下独立运行三次，后半段结果完全一致：

| 指标 | 三次结果 |
|---|---:|
| 平均输出 | `47.983414V` |
| 与 48V 的差值 | `-16.586mV` |
| 纹波峰峰值 | `0.061135Vpp` |
| 交流纹波 RMS | `15.16mVrms` |
| `<0.1Vpp` 判定 | 三次全部通过 |

当前要求已经放宽为“固定 1:2 匝比下允许接近 48V，但后半段纹波必须小于 0.1Vpp”，因此本轮结果通过。平均值没有伪装成精确 48.000V。

## 2. 为什么原输出端还有优化空间

### 2.1 两只输出“EMI 电感”并不是共模扼流圈

旧模型在输出正、负回路中各串了一只独立的 `2.2uH` 电感：

- `LOUT_EMI_Pos_Choke`
- `LOUT_EMI_Return_Choke`

它们没有互感和耦合关系，因此从差模输出电流看，相当于额外串联：

```text
2.2uH + 2.2uH = 4.4uH
```

真正的共模扼流圈依靠两绕组强耦合：正常差模电流产生的磁通大体抵消，而共模电流产生的磁通相加。用两只互不耦合的独立电感代替，会把它错误地变成差模滤波器，带来额外压降和谐振。

旧输出主通路的总差模电感近似为：

```text
2.2uH 主电感 + 4.4uH 两只独立电感 = 6.6uH
```

这会把输出网络的低频谐振点拉低到可见范围。最终模型删除这两个错误支路，输出主功率回路只保留真实的 `2.2uH` 功率电感。

如果后续 EMC 实测确实需要输出共模抑制，应增加一个有明确耦合系数、漏感、额定电流和 DCR 的真实双绕组共模扼流圈模型，而不是重新放回两只独立电感。

### 2.2 输出大电容必须从“参数”落实为电容组

旧优化值为 `4700uF/10mOhm`，但没有对应到具体物料。新版采用：

```text
8 x UR080M102J35TC97S00A
每只：1000uF / 80V / ESR 31mOhm / 3.4A ripple@100kHz
```

并联后的名义值为：

```text
Ceq = 8 x 1000uF = 8000uF
ESReq = 31mOhm / 8 = 3.875mOhm
总纹波额定 = 8 x 3.4A = 27.2A
```

这三个数已经直接写入保存的 Simulink 电容块，避免“BOM 是一回事、仿真又是另一回事”。

### 2.3 MLCC 不能按名义容量直接写入 48V 工况

输出物理方案仍使用 5 只 `22uF/100V/X7R`：

```text
名义总容量 = 110uF
```

但 X7R 在直流偏压下会损失有效容量。由于当前资料没有给出完整的 48V 偏压曲线，最终模型没有继续把名义 `110uF` 当成真实有效值，而是保守写成：

```text
有效容量 = 44uF
等效 ESR = 2mOhm
```

这不会让波形更“好看”，反而是在避免过度理想化。

## 3. 输出功率电感为什么选 MTP2920-2R2MC

最终值：

| 参数 | 数值 |
|---|---:|
| 电感量 | `2.2uH` |
| 额定电流 | `30A` |
| 直流电阻 | `2.5mOhm` |
| 饱和电流 | `100A` |
| 外形 | `28 x 27 x 21.5mm` |

在 `48V/500W` 时，平均输出电流约为：

```text
Iout = 500W / 48V = 10.42A
```

所以 30A 额定电流相对平均电流有约 `2.9` 倍余量，100A 饱和电流也能承受短时尖峰。需要注意：额定电流和饱和电流不等于“在 300kHz 下一定不发热”，实板仍必须测磁芯和绕组温升。

## 4. MOSFET 重新选型

### 4.1 最终首选：AONS66917

关键数据：

- `Vds = 100V`
- `Id = 100A`，但实际连续能力由 PCB 铜皮和温升决定
- `Rds(on) typ = 2.9mOhm @ 10V`
- `Qg = 80nC`
- `Ciss = 5.94nF`
- `Crss = 24pF`
- `Coss = 1.475nF`

与旧 `IPT015N10N5` 相比，它的室温导通电阻更大，但门极电荷和输入电容明显更低。300kHz 下，开关和驱动损耗不能只看 `Rds(on)`。

候选模型比较：

| 器件 | 工况 | 模型效率 | 输出纹波 |
|---|---:|---:|---:|
| IPT015N10N5 | 24V/48V/100W | `78.40%` | `0.04480Vpp` |
| AONS66917 | 24V/48V/100W | `79.49%` | `0.05872Vpp` |
| IPT015N10N5 | 24V/48V/500W | `80.89%` | `0.03976Vpp` |
| AONS66917 | 24V/48V/500W | `82.43%` | `0.03954Vpp` |

因此 AONS66917 在当前模型中 100W 提高约 `1.09` 个百分点，500W 提高约 `1.54` 个百分点，同时纹波仍满足要求。旧 IPT015N10N5 保留为合格替代料，但不再作为首选。

### 4.2 模型效率为什么不能直接当成实机效率

模型包含 MOSFET 导通、电容、驱动网络和若干电阻损耗，但没有完整覆盖：

- 变压器频率相关磁芯损耗；
- 绕组趋肤和邻近效应；
- PCB 铜箔和连接器损耗；
- 输出电感磁芯损耗；
- 驱动隔离电源损耗；
- 器件温升对参数的动态影响。

所以这里的效率适合比较候选器件，不适合承诺实机效率。

## 5. 栅极驱动重新选型

每个半桥采用一颗 `UCC21520DWR`，共 4 颗。每颗驱动高、低侧两个 MOSFET。

建议的实际驱动网络：

```text
5V 控制侧
  -> NMK0512SAC 隔离 DC/DC，输出 12V/2W
  -> UCC21520 低侧供电
  -> STPS1H100A + 470nF 自举给高侧供电
  -> 4.7Ohm 开通电阻
  -> 1.2Ohm + 转向二极管关断支路
  -> 100k 栅源下拉
  -> 12V 栅源齐纳钳位
```

按每只 MOSFET `Qg=80nC`、`fs=300kHz` 估算，一个半桥两只 MOSFET 的门极充放电功率近似：

```text
Pgate = 2 x Qg x Vgate x fs
      = 2 x 80nC x 12V x 300kHz
      = 0.576W
```

2W 模块比旧 BOM 中未确定的 1W 模块更有余量。模块是非稳压输出，所以增加 12V 栅源钳位，并在空载、半载、满载下测实际输出电压。

## 6. 电流和电压采样

### 6.1 输入电流

- 分流器：`1mOhm / 5W`
- 隔离放大器：`AMC3302DWER`
- 满量程：`50mV / 1mOhm = 50A`

`24V/500W` 仿真输入峰值为 `27.43A`，分流器瞬时损耗约：

```text
P = I^2 R = 27.43^2 x 0.001 = 0.752W
```

即使按 40A 设计，损耗约 `1.6W`，5W 分流器仍有余量。必须采用 Kelvin 四线取样。

### 6.2 输出电流

输出使用两只 `1mOhm/5W` 串联，形成 `2mOhm`：

```text
48V/500W: Iout = 10.42A
Vshunt = 10.42A x 2mOhm = 20.8mV
AMC3302 differential output about 20.8mV x 41 = 0.853V
```

这样比单只 1mOhm 的采样幅度更大，同时仍远低于 AMC3302 的 ±50mV 输入范围。

### 6.3 电压采样

Vout 使用 `2 x 100k` 上臂和 `3.24k` 下臂：

```text
60V -> 60 x 3.24k / (200k + 3.24k) = 0.956V
```

可覆盖 48V 正常输出和一定过压余量。Vin 使用 `2 x 100k + 6.34k`，32V 映射约 `0.984V`。

## 7. 保护和连接

### 7.1 硬件过流

`TLV3201AIDCKR` 直接驱动：

- RA8P1 的 POEG 硬件关断输入；
- UCC21520 的 `DIS`；
- 软件故障记录输入。

这样故障关断不依赖 10us 控制周期。

### 7.2 TVS

- 输入：`SMCJ36A`，36V 工作反向电压，58.1V 钳位。
- 输出：`SMCJ54A`，54V 工作反向电压，87.1V 钳位。

输出 TVS 的钳位电压已经接近 100V MOSFET的绝对额定值，因此 TVS 不能代替低电感布局和 RC 吸收。实测 Vds 重复尖峰如果接近 90V，应先调整换流回路、栅极电阻和吸收网络。

### 7.3 保险丝和连接器

- 输入保险丝：Littelfuse `142.5631.5502`，58V/50A BF1/MIDI。
- 输入连接器：Amass `XT90S` 防打火，输入线束按 40A 设计。
- 输出连接器：Amass `XT60H`，输出最大平均电流约 10.42A。

## 8. 多工况应力矩阵怎么理解

最终模型额外运行了 18V、24V、32V 输入以及 100W、500W 负载组合。

| Vin | Ptarget | 平均 Vout | Vpp | 输入峰值 | 输出平均 |
|---:|---:|---:|---:|---:|---:|
| 18V | 100W | 46.626V | 0.7449V | 5.15A | 2.01A |
| 24V | 100W | 47.983V | 0.0605V | 7.16A | 2.08A |
| 32V | 100W | 47.682V | 0.0520V | 8.53A | 2.07A |
| 18V | 500W | 45.423V | 1.5494V | 21.82A | 9.84A |
| 24V | 500W | 48.000V | 0.0387V | 27.43A | 10.42A |
| 32V | 500W | 48.072V | 0.0712V | 21.87A | 10.43A |

18V 工况没有达到 48V，原因不是输出滤波器，而是当前 MCU 相移和积分修正上限限制了传输功率。短仿真又使用了 48V 电容初值，电容在欠功率时向负载放能，因此 18V 工况短窗计算出的“效率大于 100%”没有物理意义，不能写进 BOM 或作为性能结论。

本轮不通过扩大相移上限来强行修好 18V 波形，因为用户本轮要求重点是电路层面和 BOM，当前正式验收点仍为 24V。若项目要求在 18V 输入下持续输出 500W，下一阶段必须同时完成：

1. 重新设计相移/电流限幅，而不是只改一行上限。
2. 从 0V 启动做长时仿真，不能预充到 48V。
3. 记录变压器电流峰值/RMS和各 MOSFET Vds 峰值。
4. 输入铜排、保险丝、连接器和分流器按至少 40A 连续校核。
5. 做变压器和 MOSFET 热设计。

因此当前版本的准确表述是：

```text
已验证：24V 标称输入，48V/100W 连续仿真，48V/500W 短时仿真。
未验证：18V 输入下的 48V 全功率持续运行。
```

## 9. PCB 落地时必须执行的检查

1. 原边和副边每个半桥的高频换流环路分别最小化。
2. AONS66917 的驱动电阻、栅源钳位和吸收网络贴近 MOSFET。
3. 每只 MOSFET 独立使用栅极电阻，不共用细长栅极走线。
4. 输入 10 只 MLCC 分散到两桥臂附近，不要排成远离功率管的一行。
5. 输出 8 只电解电容采用对称、等长、低阻铜皮连接。
6. 输入和输出分流器严格使用 Kelvin 走线。
7. 模拟采样地、数字控制地和功率回流按隔离边界布置。
8. 首板从 24V/20W 开始，依次升到 50W、100W、300W、500W。
9. 每级都测 Vds、Vgs、变压器电流、输出电感电流和温升。
10. 500W 只能在 100W 热测试、过流关断和过温降额均通过后进行。
