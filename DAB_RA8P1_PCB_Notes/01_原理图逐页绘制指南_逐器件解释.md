# 原理图逐页绘制指南与逐器件解释

本文按“你在 EDA 中应该画成哪些页”来写。每页先给电流路径，再说明每个器件为何存在。网络名建议照抄，避免后期 PCB 时把三个地混在一起。

## 第 1 页：输入连接、保险、浪涌与 EMI

### 1.1 主电流顺序

建议顺序：

JIN+ → F1 → 可选反接保护位 → DTVS_IN → 输入共模扼流圈正绕组 → IIN 分流器所在直流母线 → 输入电容 → 原边全桥。

JIN- → 输入共模扼流圈负绕组 → IIN 分流器低端/PRI_PGND。

网络名：

- VIN_RAW_P、VIN_RAW_N：连接器刚进入主板。
- VIN_FUSED_P：保险丝之后。
- VIN_EMI_P、VIN_EMI_N：共模扼流圈之后。
- PRI_DC_P、PRI_PGND：原边全桥最终直流母线。

### 1.2 器件

| 位号 | 选型/数值 | 作用 | 为什么这样选 |
|---|---|---|---|
| JIN | M5 铜柱端子 + XT90S 线束，或 XT90PB-M | 低压大电流输入 | 18V/300W 时输入约 19A，500W 短时可超过 30A；不要用普通 5.08mm 接线端子 |
| F1 | Littelfuse BF1/MIDI 58V 50A，142.5631.5502 | 线束和板级灾难短路保护 | 它不代替电子过流；50A 是为了允许 500W 短时，不是让 MOS 承受 50A 故障 |
| FH1 | 匹配 M5 螺栓保险座 | 可靠接触 | 保险丝放在连接器后 30mm 内 |
| DTVS_IN | SMCJ33A | 钳制输入浪涌 | 33V 反向工作电压不在正常 32V 输入下导通，典型钳位约 53V，给 63V 电解留余量 |
| LCM1 | 定制双绕组共模扼流圈 | 抑制线缆共模噪声 | 每绕组 2mH、30A、DCR≤3.5mΩ；12 匝、2.3mm 线、48/27/16mm 磁环；两绕组方向必须正确 |
| CIN1–CIN4 | 4×EKZN630ELL102ML25S | 低频储能 | 合计 4000µF/63V；承担输入源阻抗和低频脉动 |
| CIN_HF1–10 | 10×TDK C5750X7S2A226M280KB | 300kHz 局部换流电流 | 每只 22µF/100V；直流偏压后容量会下降，必须分布在两个原边半桥旁 |
| CIN_FILM | 2.2µF/100V 低 ESR 聚丙烯薄膜 | 介于 MLCC 与电解之间的频段 | 不是交流安规 X2 电容；它跨 PRI_DC_P 与 PRI_PGND |
| RDAMP/CDAMP | 0.33Ω/2W 串 40–100µF/100V，首板可调 | 抑制输入线缆/滤波谐振 | 先预留 0.1–1Ω 和多颗 MLCC 焊盘；最终根据阻抗和启动波形调整 |
| RBLEED_IN | 4×20.0kΩ/0.5W 并联，总 5kΩ | 输入电容断电泄放 | 32V 总功耗约 0.205W，明显缩短维护等待时间 |

### 1.3 不能省略的细节

- TVS 必须在保险丝后面。TVS 短路失效时要能让保险丝断开。
- XT90S 的防打火电阻只处理插接瞬间，不是输出软启动，也不能替代 MCU 相移斜坡。
- 共模扼流圈的两个绕组要同时穿过正、负线。不要把两只独立 2mH 电感误画成共模扼流圈。
- 所有输入 HF 电容的回路终点是原边半桥的 PRI_PGND，不是连接器负端的远处铜皮。
- 首板可预留 LM74700-Q1 + 两只并联 100V N-MOS 的理想二极管反接保护区域，但若没有完整照数据手册画好，宁可 DNP 并使用有方向的 XT90S，也不要自创接法。

## 第 2 页：控制岛隔离辅助电源

### 2.1 为什么要单独做这一页

RA8P1 开发板可能通过 USB 连电脑。如果控制地直接接输入负极，电脑地、示波器地和原边功率地会形成不可控回路。为实现最佳隔离，控制岛电源也从主功率输入隔离。

### 2.2 主线器件

| 位号 | 选型/数值 | 作用 |
|---|---|---|
| F_AUX | 1206SFS150F/63，1.5A/63V 慢断 | 辅助支路保险，放在 TPS26600 前 |
| U_AUX_PROT | TPS26600PWP | 866kΩ/30.1kΩ 设置约 35.4V OVP；8kΩ 设置约 1.5A 限流；47nF 设置约 12ms 斜坡 |
| C_AUX_IN | 100µF/63V + 1µF/63V + 100nF/100V | eFuse 输出和 URH 输入去耦 |
| U_AUX | MORNSUN URH2405LP-20WR3 | 9–36V 输入、最大 40V、5V/4A、20W；数据手册给出 5kVAC 耐压，但厂家当前网页提示 2024-05-01 后 UL 认证无效，因此只按竞赛样机电气隔离目标使用，形成 5V_CTRL/DGND_CTRL |
| C_AUX_OUT | 2×100µF/10V + 1µF + 100nF | 支撑 RA8P1、四块驱动板和模拟前端的瞬态 |
| U_AFE_LDO | TLV77333PDBVR | 从 5V_CTRL 生成干净的 3V3_AFE |
| C_LDO | 按数据手册的输入/输出 1µF，并联 100nF | 保证 LDO 稳定和高频去耦 |

四块驱动板在最大门极电荷下，每块约需 0.7–0.9W 隔离侧功率；加上 RA8P1 和采样，5V_CTRL 设计为至少 2A，URH2405 的 4A 额定有足够余量。

SMCJ33A 的最大钳位约 53V，高于 URH2405 的 40V 最大输入，因此 eFuse 不能省。TPS26600 的 UVLO 接 RTN 使用内部约 15V 门槛，MODE 悬空，SHDN 留空并设测试点；RTN 与 GND 按 TI 推荐网络分开，FLT 只留 PRI_POWER 测试点，不跨到 CTRL_ISLAND。

注意：厂家产品页当前明确提示 2024-05-01 之后的 UL 认证无效。因此本选型只适用于竞赛样机的电气隔离目标，不能写成“具备有效 UL 认证”，更不能推导为整机认证。若未来做认证产品，必须换成认证状态明确的等效模块并重新核对爬电、间隙和耐压测试。

### 2.3 USB 和板载 5V 的冲突

必须放电源选择跳帽或理想二极管，不允许把 RA8P1 开发板 USB 5V 与 5V_CTRL 直接硬并联。推荐三种模式只选一种：

1. 正常运行：URH2405 输出给主板和 RA8P1。
2. 纯代码调试：USB 只给 RA8P1，四块驱动板保持无电或 DIS。
3. 外部隔离 5V：从 J_5V_EXT 输入，断开 URH2405 输出跳帽。

## 第 3 页：原边全桥

原边全桥包含两个完全相同的半桥：PRI_A 和 PRI_B。每个半桥使用两只 AONS66917。

| 位号 | 选型/数值 | 作用和说明 |
|---|---|---|
| Q1–Q4 | AONS66917 | 100V、Rds(on) 典型 2.9mΩ@10V、Qg 典型 80nC；100V 对 32V 母线有足够静态余量，但必须把尖峰压在约 80V 以下 |
| CPRI_A_HF、CPRI_B_HF | 每腿至少 4×22µF/100V TDK C5750 | 给每个半桥提供本地换流电流；不能把所有 MLCC 排在远处 |
| RC_SN_Q1–Q4 | 每管 330pF–1nF C0G/≥100V 串 4.7–15Ω/2W | 吸收 Vds 振铃；首装建议 470pF+10Ω或 DNP，双脉冲实测后定值 |
| ZBUS_PRI | SMCJ33A，靠近原边桥局部母线 | 处理母线级浪涌，不代替每管 RC |
| TP_GS、TP_DS | 成对测试点 | 必须能用短弹簧地或差分探头测 Vgs/Vds |

连接原则：

- 每个高侧漏极接 PRI_DC_P。
- 高侧源极与低侧漏极形成 PRI_SW_A 或 PRI_SW_B。
- 每个低侧源极的大电流端接 PRI_PGND。
- 另外从低侧源极焊盘单独引一根 SL_KELVIN 到驱动板，不得先经过大电流铜皮。
- 高侧源极的 SH_KELVIN 从其源极焊盘单独回驱动板。
- 变压器原边接 PRI_SW_A 与 PRI_SW_B。

## 第 4 页：副边全桥

副边与原边结构相同，位号 Q5–Q8，母线为 SEC_DC_P/SEC_PGND，开关节点为 SEC_SW_A/SEC_SW_B。

差别：

- 正常母线最高 48V，硬件过压理论跳闸约 52.01V、释放约 51.49V。
- 局部母线 TVS 使用 SMCJ48A。
- 100V MOS 的尖峰设计目标仍是 Vds<80V；SMCJ48A 的大电流钳位接近 77V，因此 PCB 寄生和 RC 吸收必须先承担主要工作。
- 副边桥旁、LOUT 前放 CSEC1–2=2×EEUFS2A470 47µF/100V、CSEC_HF1–8=8×10µF/100V 软端头 MLCC，以及 ZBUS_SEC=SMCJ48A。

## 第 5 页：高频变压器和总传输电感

### 5.1 首板下单规格

| 参数 | 要求 |
|---|---|
| 磁芯 | PQ4040，TDK PC95 或明确等效材料 |
| 匝比 | Np:Ns=1:2，不允许为凑输出电压私改 |
| 建议匝数 | 3:6 匝 |
| 原边励磁电感 | 57.5µH，容差建议 ±10% |
| 副边励磁电感 | 230µH，容差建议 ±10% |
| 总副边折算漏感 | 0.50µH，验收建议 ±0.05µH，至少记录 ±0.10µH |
| DCR | 原边≤0.95mΩ；副边≤3.0mΩ，25°C |
| 绝缘 | 至少一个绕组采用三层绝缘线；原副边爬电≥8mm；样品做 4kVAC/60s 或由厂家按等效强化绝缘规范出具记录 |
| 绕组电容 | 原副边电容目标≤100pF，实测记录 |
| 温升 | 300W 连续、300kHz、规定风量下温升目标≤60°C |

全桥方波磁通估算：

ΔB≈Vin/(4·Np·Ae·fs)

以 Ae≈201mm²、Vin=32V、Np=3、fs=200kHz 计算，ΔB 约 0.066T；在 300kHz 约 0.044T。因此 3:6 匝比 2:4 更有励磁电感和降频余量。

建议初始导线：

- 原边：总铜截面积约 8–10mm²，例如多束 0.10mm 单丝绞合的利兹线并绕。
- 副边：总铜截面积约 4–5mm²。
- 300kHz 铜的趋肤深度约 0.12mm，单丝直径不宜明显大于 0.20mm。

这些是给变压器厂的起始约束，不是允许厂家只按“3:6 匝”盲绕。最终要同时满足窗口填充、漏感、DCR、绕组电容和温升。

### 5.2 必须留调试接口

在副边传输路径串入 LTRANSFER_LINK 位置：

- 正常装粗铜排 0Ω 跳线。
- 两侧各放 M4/M5 铜柱或大焊盘。
- 如果首个变压器漏感偏低，可串外置 0.1–0.3µH 高电流电感。
- 如果漏感偏高，只能调整绕法或重做变压器，不能靠控制器假装电感变小。

不要把 2.2µH 输出滤波电感当成 DAB 的 0.5µH 传输漏感；它们位置、作用和电流波形完全不同。

## 第 6 页：四块完全相同的半桥驱动小板

每块板包含 UCC21520、UCC33421、TLV61046A、死区网络、自举网络和两路门极网络。

### 6.1 控制侧

| 器件 | 数值/型号 | 作用 |
|---|---|---|
| UDRV | UCC21520DWR | 两通道强化隔离门极驱动，4A 拉高/6A 拉低 |
| CVCCI | 100nF + 1µF | VCCI=3V3_DRV 去耦，距引脚小于 3mm |
| RINA/RINB | 33–51Ω | 抑制连接器和数字线振铃 |
| RPD_INA/RPD_INB | 10kΩ | RA8P1 复位或小板拔掉时保证输入低 |
| RDT | 10.0kΩ/1% | UCC21520 内部最小死区典型 100ns、范围约 80–120ns |
| CDT | 330pF C0G，且≤1nF | 提高 DT 引脚抗噪声和通道匹配 |
| UDIS | SN74LVC1G10 | 三输入 NAND：DIS=NOT(RUN_REQ AND FAULT_LATCH_N AND ESTOP_N) |
| RPD_RUN | 10kΩ | 上电默认 RUN_REQ=0，因此 DIS=1、两路输出关闭 |
| RPD_FAULT/RPD_ESTOP | 各 47kΩ | 两条允许线断开时，本板 DIS 立即变高 |
| RPU_DIS | 10kΩ | UDIS 漏焊、损坏或输出未建立时仍把 UCC21520 保持关断 |

UCC21520 的 DIS 高电平关闭两路输出。不要依赖 DIS 悬空状态；使用本地逻辑主动给出安全电平。DIS 到 UCC 的线要短，最多并 100–220pF；不要在快速硬件关断路径上随意放 1nF 以上电容。

| CIN_ISO_HF | 15nF/50V X7R | VINP 与 GNDP，必须贴引脚 |
| CIN_ISO | 10µF/10V X7R | VINP 与 GNDP，必须贴引脚 |
| COUT_ISO_HF | 15nF/50V X7R | VCC 与 GNDS，必须贴引脚 |
| COUT_ISO | 22µF/10V X7R | VCC 与 GNDS，必须贴引脚 |
| R_ENFLT | 22kΩ/1% | EN/FLT 到 5V_CTRL；避免 18kΩ 负公差越过数据手册下限；故障时拉低约 200µs |
| SEL | 接 VCC | 选择 5.0V 输出 |
| UBOOST | TLV61046ADBVR | 把隔离 5V 升到约 10V |
| LBOOST | SDR0302-150ML，15µH | TLV61046A 储能电感 |
| CIN_BOOST | 1µF/10V + 100nF | 贴近 VIN；共享 UCC 输出唯一的 22µF，禁止再装第二颗 22µF |

旧 71.5kΩ/10kΩ 只能得到约 6.48V，低于 UCC21520 的 8V UVLO，禁止使用。TLV EN 约 6–9ms 后开启；MCU 至少等待 30ms，并确认没有 PWRFLT，才能拉高 RUN_REQ。

按 AONS66917 典型 Qg=80nC、Vg=10.18V 估算，每个半桥：

Pgate≈2·Qg·Vg·fs≈2×80nC×10.18V×300kHz≈0.49W。

按最大 Qg=115nC 约为 0.70W；加驱动静态损耗并按保守 80% 升压效率，UCC33421 隔离输出负担接近 0.99W。UCC33421 在环境温度不高于 85°C 时额定 1.5W、105°C 时降为 1W、125°C 时仅 0.5W，因此驱动板局部环境温度目标不高于 85°C，达到 95°C 必须降功率，达到 105°C 必须停机。UISO 不得直接悬在 MOS 或散热器热羽流上方。

## 第 7 页：快速变压器电流测量与硬件过流

### 7.1 传感器位置

- U_IPRI 串在变压器原边一根交流引线中。
- U_ISEC 串在变压器副边一根交流引线中。
- 两者都测双向高频电流，不放在大电容上游的“平均电流”位置。

### 7.2 器件和阈值

| 位号 | 选型 | 量程/阈值 |
|---|---|---|
| U_IPRI | TMCS1133B7AQDVGR | 3.3V 供电，20mV/A，线性约 ±77.5A |
| U_ISEC | TMCS1133B7AQDVGR | 3.3V 供电，20mV/A，线性约 ±77.5A；与原边统一料号 |
| R_VOC_PRI | 10.0kΩ/1.91kΩ，0.1% | 原边 VOC 分压，目标约 0.522V |
| R_VOC_SEC | 9.24kΩ/1.00kΩ，0.1% | 次级 VOC 分压，目标约 0.320V |
| C_VOC | 10µF + 100nF | 稳定过流阈值 |
| R_OC_PU | 4.7kΩ | OC 开漏输出上拉到 3V3_AFE |
| C_VS | 10µF + 100nF | 每颗 TMCS 的供电去耦 |
| R_ADC/C_ADC | 47Ω + 1nF | VOUT 到 RA8P1 ADC 的小 RC |

考虑 VOC 引脚约 120kΩ 输入阻抗，原边 VOC 约 0.522V，次级 VOC 约 0.320V。过流阈值公式为：

IOC≈2.5·VOC/S。

两侧 B7A 灵敏度均为 20mV/A，因此原边约 65A，次级约 40A。TMCS1133 的 OC 在输入达到阈值约 120% 时，响应典型约 100ns、最大约 250ns；加上锁存、NAND 和 UCC21520 DIS，首板目标总关断约 0.35µs 以内。

TMCS1133 电流导体约 0.7mΩ。它在高电流下会发热，电流脚必须接大铜面和密集热过孔；不能把细颈铜皮当保险丝。ALERT 是温度/传感器诊断 PWM，只接 MCU GPIO，不要与 OC 直接短接。

## 第 8 页：输入/输出直流电流精密采样

TMCS 用来保护变压器和观察高频电流；分流器用来得到准确的输入、输出直流电流和功率。

### 8.1 分流器

| 位号 | 选型 | 满量程 |
|---|---|---|
| RSHUNT_IN | CSS2H-2512R-1L00F，1mΩ | AMC3302 的 ±50mV 对应 ±50A |
| RSHUNT_OUT1/2 | 两只同型号串联，总 2mΩ | ±50mV 对应 ±25A |
| U_IIN/U_IOUT | AMC3302DWER | 增益 41，强化隔离，集成隔离电源 |

输入分流器放在共模扼流圈后、输入大电容前的直流回路；输出分流器放在输出电容后、负载连接器前。这样测到的是外部输入/输出直流，不承担纳秒级短路关断。

### 8.2 AMC3302 高压侧

- 分流器每一端各串 10Ω 到 INP/INN。
- INP 与 INN 之间放 10nF。
- HGND 用第三根独立 Kelvin 线回到分流器低端，不能在 AMC 引脚处随意短接到 INN。
- DCDC_OUT、HLDO 和 VDD 的 1nF/100nF/1µF 去耦严格照数据手册，全部贴近对应引脚。
- DIAG 以 10kΩ 上拉到 3V3_AFE，送慢速故障 GPIO。

### 8.3 差分转单端

AMC3302 满量程差分输出约 ±2.05V。为了保留双向电流并适配 0–3.3V ADC：

- 使用 TLV6004 的两个通道。
- 输入电阻 R1=R3=4.02kΩ/0.1%。
- 反馈/参考电阻 R2=R4=3.01kΩ/0.1%。
- 比例约 0.749。
- 参考电平接 REF2033 的 VBIAS=1.65V。
- 匹配电容 330pF C0G。

结果近似：

VADC=1.65V+0.749·(OUTP-OUTN)。

零电流约 1.65V，正负满量程约 0.11–3.19V。

## 第 9 页：输入/输出隔离电压采样

| 通道 | 上臂 | 下臂 | 对应范围 |
|---|---|---|---|
| Vin | 2×100kΩ/0.1% 串联 | 5.62kΩ/0.1% | 36V 时 AMC 输入约 0.984V |
| Vout | 2×100kΩ/0.1% 串联 | 3.24kΩ/0.1% | 60V 时 AMC 输入约 0.956V |

U_VIN/U_VOUT 均用 AMC3330DWER。两只 100k 串联是为了降低单个电阻的工作电压、提高脉冲可靠性和单点失效余量。分压电阻远离开关节点，INP-INN 之间放 1nF C0G。

AMC3330 输出用 TLV6004 另外两个通道转换：

- R1=R2=R3=R4=10kΩ/0.1%。
- C1=C2=1nF C0G。
- VREF 接 AGND。
- 输出近似为 OUTP-OUTN。
- 每路 ADC 前再加 47Ω+1nF。

## 第 10 页：参考电压、硬件过压和故障锁存

### 10.1 参考

U_REF=REF2033AIDDCR，输入来自 5V_CTRL，输出：

- VREF_3V3=3.3V。
- VBIAS_1V65=1.65V。

两路均按数据手册放稳定电容。VBIAS 同时供双向电流调理和一个 RA8P1 校准 ADC 通道。

### 10.2 硬件过压

U_OV=TLV3202AIDR 双比较器。

- VOUT_OV：ADC_VOUT 接 IN−；VBIAS_1V65 经 4.99kΩ接 IN+，比较器原始输出经 1MΩ回 IN+。理论跳闸约 52.01V、释放约 51.49V。
- VIN_OV：ADC_VIN 接 IN−；VREF_3V3 经 7.68kΩ/10.0kΩ分压形成 IN+，比较器原始输出经 1MΩ回 IN+。理论跳闸约 34.26V、释放约 34.00V。
- 比较器配置为正常输出高、过压输出低。
- 比较器推挽输出先进入 SN74LVC2G07 开漏缓冲，再汇入 RAW_FAULT_N。

### 10.3 故障总线与锁存

RAW_FAULT_N 是 3.3V 开漏线，4.7kΩ 上拉，100pF 以内小电容。以下任一信号可拉低：

- IPRI_OC_N。
- ISEC_OC_N。
- VIN_OV_N。
- VOUT_OV_N。
- ESTOP_N。
- 四块 UCC33421 的 PWRFLT_N，经开漏汇总。

急停接口 J_ESTOP 使用常闭回路：3V3_DRV 经 1kΩ 到连接器一端，另一端返回 ESTOP_SENSE；ESTOP_SENSE 用 10kΩ 下拉和 1nF 小电容，再经 SN74LVC1G17 施密特非反相缓冲生成 ESTOP_N。按钮正常闭合时 ESTOP_N 为高，按钮动作、线缆断开或插头脱落时立即变低。ESTOP_N 一路直达四块驱动板 NAND，另一路进入 SN74LVC07A CH6 后开漏拉低 RAW_FAULT_N；不允许只让急停进入 MCU。

四路 PWRFLT 分别进入主板 SN74LVC07A CH1–CH4，输入各有 100kΩ 下拉；四个开漏输出并成 AUX_PG_N，2.2kΩ 上拉到 3V3_DRV。CH5 再把 AUX_PG_N 汇入 RAW_FAULT_N。驱动板脱插因此也是锁存故障。

U_LATCH=SN74LVC1G74：

- /PRE 接 RAW_FAULT_N。
- /CLR 接 FAULT_RESET_N。
- D 和 CLK 接低。
- Q=FAULT_LATCHED，高表示已锁存故障。
- /Q=FAULT_LATCH_N，正常为高，故障后保持低。

FAULT_RESET_N 用 10kΩ 上拉到 3V3_DRV；MCU 使用开漏输出，经 1kΩ 接 /CLR。只有所有原始故障释放、RUN_REQ=0 后才能给约 20µs 低脉冲。/PRE 和 /CLR 禁止同时为低，也禁止用上电 RC 自动清零。上电时 RUN_REQ 有主板和驱动板两级下拉，即使锁存器状态尚未建立，四块驱动板仍保持 DIS。

RAW_FAULT_N 同时直接进入 RA8P1 POEG，软件不参与第一拍关断。FAULT_LATCHED 进入普通 GPIO，供软件记录原因和决定是否复位。

## 第 11 页：输出滤波与连接

### 11.1 顺序

副边全桥局部母线 → CSEC1–2/CSEC_HF1–8/ZBUS_SEC → LOUT → COUT_HF1–8/COUT1–8/RBLEED/VOUT采样 → FOUT → 输出分流器 → JOUT。DTVS_CONN 单独放在 FOUT 后、JOUT 旁。

| 位号 | 选型 | 作用 |
|---|---|---|
| CSEC1–2 | 2×EEUFS2A470，47µF/100V | LOUT 前副边桥局部阻尼和中频储能，并联总 94µF |
| CSEC_HF1–8 | 8×TDK C5750X7S2A106K230KE | LOUT 前；每个副边半桥 4 只，48V 有效总容量目标≥40µF |
| ZBUS_SEC | SMCJ48A | LOUT 前副边桥局部母线钳位 |
| LOUT | Coilcraft SER2915H-222KL | 2.2µH，DCR 最大 2.05mΩ，Isat>100A，Irms 30A@40°C 温升 |
| COUT_HF1–8 | 另 8×TDK C5750X7S2A106K230KE | LOUT 后；与 CSEC_HF 是两组不同器件 |
| COUT1–8 | 8×UR080M102J35TC97S00A | 合计 8000µF/80V，额定纹波电流合计约 27A |
| RBLEED_OUT | 2×2.49kΩ/1W 串联 | FOUT 前跨 COUT 星点，48V 到 5V 约 90s |
| FOUT | PV-15A10-2P | 15A/1000VDC/50kA；切断 8mF 对外部硬短路放电 |
| DTVS_CONN | SMCJ48A | FOUT 后、JOUT 旁的接口线缆浪涌钳位 |
| JOUT | XT60H 线束或 M4/M5 铜柱 | 48V/10.4A 短时输出，保留足够接触余量 |

SER2915H-222KL 的官方电感测试频率为 500kHz，DCR 和电流曲线完整，优先于只有 100kHz 关键数据的 MTP2920。它仍需在实际 300kHz 纹波下测磁芯温升。

输出 2.2µH 与 8000µF 会形成约 1.2kHz 的后级谐振，因此：

- 控制电压环带宽不能直接跨过该谐振而不做补偿。
- 首板 LOUT 两端必须留低电感铜排旁路位，便于对比有/无后级电感。
- 首次启动可先装 4 只输出电解，低功率确认软启动后再补齐 8 只。
- 最终纹波、阶跃和环路稳定性以装齐目标电容后的实测为准。

## 第 12 页：温度和通信

### 12.1 温度

不要把普通 0603 NTC 一端接功率地、另一端直接送控制板，这会破坏隔离。

推荐：

- U_TMP_PRI、U_TMP_SEC：ISOTMP35BEDFQRQ1，分别放在原边和副边 MOS 热区，隔离模拟输出送 RA8P1。
- T1、LOUT、COUT 采用封装式 10k/B3950 热敏珠，双层绝缘套管和绝缘胶固定；其两根线始终属于 CTRL_ISLAND，不与磁芯、铜排或散热器电连接。
- 每路 10k 上拉到 VREF_3V3，ADC 前 1k+100nF，采样频率 10–100Hz 即可。

### 12.2 通信

主板保留 CANTX、CANRX、UART_TX、UART_RX 和 I2C/SPI 扩展网络。若比赛需要长线 CAN，主线建议：

- ISO1042BDWR 隔离 CAN 收发器。
- 第五颗 UCC33421 给总线侧提供 5V_CAN。
- 总线端 120Ω 终端电阻用跳帽选择。
- CANH/CANL 放专用 TVS 和共模扼流圈。

RS485 不与 CAN 共用收发器，可放在独立扩展小板。不要为了“接口齐全”在首板同时装两套未经使用的高速总线。

## 原理图完成后的逐网检查

在开始 PCB 前逐项打勾：

- PRI_PGND、SEC_PGND、DGND_CTRL/AGND_CTRL 没有任何 0Ω、安装孔或屏蔽层误连。
- 八只 MOS 都有独立 Rg_on、Rg_off、Dg、Rgs、Zgs。
- 四块驱动板的 UCC33421 输入/输出电容数值和地完全分域。
- 四个 UCC21520 的 DIS 上电都确定为高。
- 两个 TMCS 都在变压器交流电流路径，而不是大电容上游。
- 两个直流分流器都有真正的 Kelvin 引脚和三线 HGND 回路。
- AMC3302/3330 的 OUTP/OUTN 没有直接接单端 ADC。
- RAW_FAULT_N 不经过 MCU 才到 DIS。
- 输出 TVS 已改为 SMCJ48A，输入为 SMCJ33A。
- LOUT 和变压器漏感在原理图上是两个不同器件/参数。
- RA8P1 物理针脚仍标为“待开发板确认”，没有凭猜测锁死。
