# RA8P1 开发板接口与硬件保护网络表

## 1. 重要前提

比赛提供的是 RA8P1 开发板，不是裸 MCU。主功率板不应直接按 R7KA8P1KFLCAC 芯片球位画线，而应先定义稳定的“功能接口”，再用一块 RA8P1 转接板把比赛开发板连接器映射到该接口。

目前 e² studio 工程使用 board.custom，尚未配置 GPT、PDG、POEG、ADC_B、DMAC 和 CAN，因此现阶段只能冻结网络名和外设要求，不能把任何猜测的 Pxxx 引脚写成最终针脚。

## 2. RA8P1 必须提供的外设资源

| 功能 | 要求 |
|---|---|
| 四个半桥 PWM | 4 组 GPT 互补 A/B 输出，共 8 路；优先 GPT0–GPT3 |
| 同步/相移 | 四个 GPT 同步启动，使用硬件缓冲更新；可用 PDG 时用 PDG 做细相位延时 |
| 死区 | MCU 初始约 120ns，同时 UCC21520 用 10k RDT 提供约 100ns 硬件下限 |
| 快速关断 | RAW_FAULT_N 必须接到可触发 POEG 的外部触发输入 |
| ADC | 至少 12 路单端 ADC，支持 PWM 定点触发 |
| 数据搬运 | ADC_B + DMAC/DTC，避免 CPU 在开关边沿附近轮询 |
| 控制中断 | 后续约 50kHz；不能用 FreeRTOS 任务直接翻 GPIO |
| 通信 | 预留 CAN-FD、UART；RS485 走扩展板 |

## 3. 主功率板标准连接器

### 3.1 JCTRL_DIG：2×16

每个高速/关键数字信号旁边放一个地针，使用带防反、锁扣的连接器。

| 针脚 | 网络 | 方向，以 RA8P1 为中心 | 说明 |
|---:|---|---|---|
| 1 | 5V_CTRL | 电源 | 隔离辅助 5V；是否给开发板供电由转接板跳帽决定 |
| 2 | DGND_CTRL | 地 | 控制岛地 |
| 3 | 3V3_AFE | 电源/参考 | 只给接口缓冲和小负载；不要反灌开发板 3V3 |
| 4 | DGND_CTRL | 地 |  |
| 5 | PWM_PRI_A_H | 输出 | 原边 A 腿高侧命令 |
| 6 | DGND_CTRL | 地 |  |
| 7 | PWM_PRI_A_L | 输出 | 原边 A 腿低侧命令 |
| 8 | DGND_CTRL | 地 |  |
| 9 | PWM_PRI_B_H | 输出 | 原边 B 腿高侧命令 |
| 10 | DGND_CTRL | 地 |  |
| 11 | PWM_PRI_B_L | 输出 | 原边 B 腿低侧命令 |
| 12 | DGND_CTRL | 地 |  |
| 13 | PWM_SEC_A_H | 输出 | 副边 A 腿高侧命令 |
| 14 | DGND_CTRL | 地 |  |
| 15 | PWM_SEC_A_L | 输出 | 副边 A 腿低侧命令 |
| 16 | DGND_CTRL | 地 |  |
| 17 | PWM_SEC_B_H | 输出 | 副边 B 腿高侧命令 |
| 18 | DGND_CTRL | 地 |  |
| 19 | PWM_SEC_B_L | 输出 | 副边 B 腿低侧命令 |
| 20 | DGND_CTRL | 地 |  |
| 21 | RUN_REQ | 输出 | 上电默认 10k 下拉；高才允许驱动板工作 |
| 22 | DGND_CTRL | 地 |  |
| 23 | RAW_FAULT_N | 输入/POEG | 未锁存、最快故障线，低有效 |
| 24 | DGND_CTRL | 地 |  |
| 25 | FAULT_LATCHED | 输入 | 高表示硬件锁存器已动作 |
| 26 | DGND_CTRL | 地 |  |

| 28 | DGND_CTRL | 地 |  |
| 29 | ESTOP_N | 输入 | 外部急停回路，低有效 |
| 30 | DGND_CTRL | 地 |  |
| 31 | AUX_PG_N | 输入 | 四块驱动隔离电源故障汇总，低有效 |
| 32 | DGND_CTRL | 地 |  |

PWM 在主功率板上以星形分别去四块驱动板。不要把多个半桥 PWM 先串过一块驱动板再到下一块。

### 3.2 JCTRL_ANA：2×12

| 奇数针 | 信号 | 偶数针 |
|---:|---|---|
| 1 | ADC_VIN | 2=AGND_CTRL |
| 3 | ADC_VOUT | 4=AGND_CTRL |
| 5 | ADC_IIN | 6=AGND_CTRL |
| 7 | ADC_IOUT | 8=AGND_CTRL |
| 9 | ADC_IPRI_HF | 10=AGND_CTRL |
| 11 | ADC_ISEC_HF | 12=AGND_CTRL |
| 13 | ADC_TEMP_PRI | 14=AGND_CTRL |
| 15 | ADC_TEMP_SEC | 16=AGND_CTRL |
| 17 | ADC_NTC_T1 | 18=AGND_CTRL |
| 19 | ADC_NTC_LOUT | 20=AGND_CTRL |
| 21 | ADC_NTC_COUT | 22=AGND_CTRL |
| 23 | ADC_VBIAS_1V65 | 24=AGND_CTRL |

所有信号在主板连接器前已有 47Ω+1nF 或 1k+100nF 滤波。转接板上只做 ESD、小串阻和针脚映射，不再重复一个未知带宽的大 RC。

### 3.3 JCOMM：2×8

| 针脚 | 网络 |
|---:|---|
| 1/2 | CANTX / CANRX |
| 3/4 | UART_TX / UART_RX |
| 5/6 | I2C_SCL / I2C_SDA |
| 7/8 | SPI_SCK / SPI_MOSI |
| 9/10 | SPI_MISO / SPI_CS |
| 11/12 | DEBUG_TRIG / SYNC_IN |
| 13/14 | 3V3_AFE / 5V_CTRL |
| 15/16 | DGND_CTRL / DGND_CTRL |

CAN 收发器若放在主功率板，JCOMM 的 CANTX/CANRX 是 MCU 逻辑信号；外部 CANH/CANL 使用另一只隔离、保护后的连接器。

## 4. 四块驱动板的 PWM 对应

| GPT 组 | 输出 A/B | 驱动板 | MOS |
|---|---|---|---|
| GPT0 | PWM_PRI_A_H/L | DRV_PRI_A | Q1/Q2 |
| GPT1 | PWM_PRI_B_H/L | DRV_PRI_B | Q3/Q4 |
| GPT2 | PWM_SEC_A_H/L | DRV_SEC_A | Q5/Q6 |
| GPT3 | PWM_SEC_B_H/L | DRV_SEC_B | Q7/Q8 |

这是功能对应，不是最终 RA8P1 物理引脚。最终要求开发板连接器必须同时引出四个 GPT 的 A/B 输出；若某个候选引脚未引出，就换 GPT/转接方式，不能退化为软件 GPIO。

## 5. 硬件故障链

~~~text
TMCS 原边 OC ─┐
TMCS 副边 OC ─┤
VIN 硬件过压 ─┤
VOUT 硬件过压 ├─ RAW_FAULT_N ─┬─ RA8P1 POEG
急停/驱动电源 ─┤               └─ SN74LVC1G74 /PRE
其他开漏故障 ──┘

SN74LVC1G74 /Q = FAULT_LATCH_N
FAULT_LATCH_N + RUN_REQ + ESTOP_N
        ↓
每块驱动板 SN74LVC1G10
        ↓
UCC21520 DIS
        ↓
八只 MOS 栅极全部拉低
~~~

软件只负责：

- 记录哪条故障先发生。
- 把 RUN_REQ 保持低。
- 等电流、电压和温度都恢复安全。
- 经人工命令后输出 FAULT_RESET_N。

软件不参与第一拍关断。

### 5.1 每块驱动板的本地失效安全

UDIS=SN74LVC1G10，A/B/C 分别接 RUN_REQ、FAULT_LATCH_N、ESTOP_N，Y 接 UCC21520 DIS。每块板必须独立安装：

- RUN_REQ 10kΩ 下拉。
- FAULT_LATCH_N 47kΩ 下拉。
- ESTOP_N 47kΩ 下拉。
- DIS 10kΩ 上拉到 3V3_DRV。
- PWM_H/PWM_L 各 10kΩ 下拉。

主板 JCTRL 处 RUN_REQ 再放一颗 10kΩ 下拉。任一允许线断开、MCU 复位或小板控制连接器松脱，都必须趋向 DIS=1。

### 5.2 急停

~~~text
3V3_DRV → 1kΩ → J_ESTOP-1 → 外部常闭干接点
J_ESTOP-2 = ESTOP_SENSE
ESTOP_SENSE → 10kΩ → DGND_CTRL
ESTOP_SENSE → 1nF → DGND_CTRL
ESTOP_SENSE → SN74LVC1G17 → ESTOP_N
~~~

断线、脱插或拍下急停都会得到低电平。ESTOP_N 同时直达四块驱动板 NAND、RA8P1 状态输入和 U_FAULT_OD 的 CH6；CH6 开漏输出汇入 RAW_FAULT_N。RA8P1 只读取状态，不负责生成第一拍关断。

### 5.3 四块 UCC33421 故障汇总

每块 UCC33421 EN/FLT 用 22kΩ/1% 上拉到 5V_CTRL，SEL 明确接隔离侧 VCC。四个 EN/FLT 不得直接并联。

主板 U_FAULT_OD=SN74LVC07APWR，使用 3V3_DRV：

- CH1–CH4 分别输入 PWRFLT1_N–PWRFLT4_N；每个主板输入放 100kΩ 下拉，拔掉小板即视为故障。
- CH1–CH4 开漏输出并成 AUX_PG_N。
- AUX_PG_N 用 2.2kΩ 上拉到 3V3_DRV，并独立送 RA8P1。
- CH5 输入 AUX_PG_N，开漏输出接 RAW_FAULT_N。
- CH6 输入 ESTOP_N，开漏输出接 RAW_FAULT_N。
- U_FAULT_OD 旁放 100nF；未使用输入不得悬空。

SN74LVC07A 输入可容忍 5V，不会把 3.3V 总线反灌到其他 EN/FLT。BAT54 不作为 PWRFLT 定版汇总器件。

### 5.4 过流和过压如何汇入 RAW_FAULT_N

IPRI_OC_N、ISEC_OC_N 各用 4.7kΩ 上拉到 3V3_AFE，并各自送 RA8P1 诊断。两路分别用 BAT54H 汇入 RAW_FAULT_N：二极管阳极接 RAW_FAULT_N，阴极接对应 OC_N。

TLV3202 两路都采用 ADC 信号进 IN−、阈值进 IN+，原始推挽输出正常高、过压低，再由 SN74LVC2G07 开漏汇入 RAW_FAULT_N：

- VIN：3V3_AFE 经 7.68kΩ/0.1% 到 VIN_THR，VIN_THR 经 10.0kΩ/0.1% 到 AGND，比较器原始输出经 1.00MΩ 回 VIN_THR。理论跳闸约 34.26V、释放约 34.00V。
- VOUT：VBIAS_1V65 经 4.99kΩ/0.1% 到 VOUT_THR，比较器原始输出经 1.00MΩ 回 VOUT_THR。理论跳闸约 52.01V、释放约 51.49V。

VOUT 的 4.99kΩ 不能省略；若 1.65V 低阻源直接接 IN+，1MΩ 正反馈几乎不能产生迟滞。

RAW_FAULT_N 用 4.7kΩ 上拉到 3V3_DRV，默认不装总线电容；抗尖峰调试电容最多 47–100pF，禁止 nF 级电容拖慢关断。

### 5.5 锁存和复位

U_LATCH=SN74LVC1G74：

- /PRE 接 RAW_FAULT_N。
- /CLR 接 FAULT_RESET_N。
- D 和 CLK 直接接 DGND_CTRL。
- Q=FAULT_LATCHED；/Q=FAULT_LATCH_N。

FAULT_RESET_N 用 10kΩ 上拉到 3V3_DRV。RA8P1 只能用开漏输出，经 1kΩ 串联到 /CLR；建议低脉冲 20µs。只有 RUN_REQ=0、RAW_FAULT_N=1 且电压、电流、温度都恢复安全时才允许复位。禁止增加对地上拉冲突或上电自动清零 RC；/PRE 和 /CLR 不能同时为低。

## 6. 上电真值要求

| 状态 | RUN_REQ | FAULT_LATCH_N | ESTOP_N | UCC21520 DIS | 结果 |
|---|---:|---:|---:|---:|---|
| MCU 复位/未初始化 | 0 | 任意 | 任意 | 1 | 全关 |
| 无故障但未授权 | 0 | 1 | 1 | 1 | 全关 |
| 正常运行 | 1 | 1 | 1 | 0 | PWM 可通过 |
| 任一硬件故障 | 任意 | 0 | 任意 | 1 | 全关并锁存 |
| 急停断开 | 任意 | 任意 | 0 | 1 | 全关并锁存 |
| 任一驱动板拔出 | 0 或不变 | PWRFLT 输入被 100k 下拉并锁存 | 任意 | 四板 DIS=1 | 全桥关断并报告 AUX_PG_N |

RA8P1 任何复位、看门狗、HardFault、下载程序状态都必须等效于 RUN_REQ=0。

### 6.1 固定磁件后的 RUN 许可

变压器和共模电感已经定制锁定，RA8P1 必须用工作域许可补上宽变比 SPS 的电流风险：

| 状态 | 进入条件 | 行为 |
|---|---|---|
| OFF | 上电默认、故障或命令停机 | `RUN_REQ=0`，八路 PWM 禁止 |
| STARTUP_CURRENT_LIMITED | `18≤Vin≤28V`、`Vout<36V`、无硬件故障 | 只允许受限 EPS/PDM/三电平窄脉冲；建议 `Ipri_pk≤35A、Isec_pk≤20A` |
| NORMAL_SPS | `18≤Vin≤28V`、`36≤Vout≤48V`、进入时 `|Vout-2Vin|≤7.5V` | 300kHz SPS；保持边界 `<8.0V`；连续降额阈值约 45A/24A，软件绝对限制约 50A/28A |
| SHORT_500W_TEST | `21≤Vin≤24V`、`|Vout-2Vin|≤4V`，并收到人工实验授权 | 只允许 1s→3s→5s 分级测试，任一温度/尖峰异常立即退出 |
| OUT_OF_RANGE | `Vin>28V`、`Vout>48V` 或正常 SPS 电压失配越界 | 禁止增加相移；受控降功率后 `RUN_REQ=0` |

`Vin=28–32V` 仍在硬件测量和输入 OVP 覆盖范围内，但不属于首版普通 SPS 正常开桥范围。该限制必须固化在状态机和测试用例中，不能只写在操作说明里。完整逐伏范围见 08 文档。

## 7. 开发板针脚冻结流程

在画 RA8P1 转接板前完成：

1. 拍下比赛开发板正反面和完整丝印。
2. 找到准确开发板名称、版本和原理图。
3. 在 e² studio FSP Pin Configuration 中确认四组 GPT A/B 均可引到实际连接器。
4. 确认至少一个外部故障针可作为 POEG 触发。
5. 确认 ADC 引脚属于可用 ADC 单元，并避免与晶振、调试、SDRAM 等板载资源冲突。
6. 用万用表确认连接器 5V、3V3、AGND、DGND 以及 USB 供电关系。
7. 先做一块廉价转接板或飞线验证 300kHz 八路 PWM，再锁主板接口。

在以上信息确认之前，主功率板可以完成所有 JCTRL 网络和布线，但 RA8P1 转接板不得送板。
