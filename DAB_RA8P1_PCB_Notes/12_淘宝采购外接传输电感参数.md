# DAB 外接传输漏感采购与实测配平说明

版本：H1.1  
日期：2026-07-12

## 1. 最终采购结论

直接读取最新版 `DAB_RA8P1_Final_Physical_MOSFET.slx` 后，模型中只有下面两项相关电感：

| 模型名称 | 电路功能 | 模型值 | 实物采购结论 |
|---|---|---|---|
| `Llk_Secondary_Transfer` | DAB 副边折算总漏感/总传输电感 | 0.50uH、0.10mOhm、最大工作电流 50A | 不是额外固定叠加 0.50uH；外接值按变压器实测漏感配平 |
| `LOUT_Filter_Inductor` | 副边桥后的直流输出滤波电感 | 2.20uH、2.05mOhm、最大工作电流 30A | 必须购买一只 2.2uH 大电流功率电感 |

所以“漏感”和“传输电感”在 DAB 交流回路里是同一个总参数，不能分别再串两只。若准备购买两只不同功能的器件，正确组合是：

1. 一组用于配平到总计 0.50uH 的 DAB 高频双向交流传输电感。
2. 一只 2.20uH 输出滤波电感 `LOUT`。

本项目中模型给出的 `0.50uH` 是**副边折算后的总传输漏感目标值**，不是要求在 PCB 上再串联一只固定 `0.50uH` 电感。

总传输漏感为：

```text
Ltotal_sec = Llk_transformer_sec + Lpcb_sec + Lexternal
目标：Ltotal_sec 约 0.50uH
```

因此首板的 `LTRANSFER_LINK` 默认安装粗铜排或低电感机械跳线。建议现在从淘宝购买以下调试件：

| 数量 | 标称电感量 | 用途 |
|---:|---:|---|
| 2 只 | 0.10uH | 小幅补偿 |
| 2 只 | 0.20uH | 中等补偿 |
| 2 只 | 0.30uH | 较大补偿 |
| 2 只 | 0Ohm 粗铜排/机械跳线 | 默认安装和对照测试 |

在没有测量已定制变压器实际漏感之前，**不要直接购买并固定安装 0.50uH**。如果变压器自身副边折算漏感已经接近 0.50uH，再串 0.50uH 会使总值接近 1uH，导致最大传输功率、相移命令、环流和 ZVS 条件全部改变。

## 2. 发给淘宝商家的硬性参数

商品名称应描述为“DAB 串联传输电感”或“高频大电流超小电感”，不要只搜索“漏感”。

| 参数 | 最低要求 | 优选要求 |
|---|---:|---:|
| 标称电感量 | 0.10/0.20/0.30uH 三种 | 三种都购买，用于配平 |
| 电感公差 | +/-10% | +/-5% |
| 测试频率 | 给出 100kHz 测量值 | 同时给出 100kHz、300kHz 测量值 |
| 工作开关频率 | 200-350kHz | 按 300kHz 优化 |
| 饱和电流 Isat | >=50A，且电感下降不超过 20% | >=60A |
| 热额定电流 Irms | >=25A，300kHz 双极性交流下温升不超过 40degC | >=30A |
| 直流电阻 DCR（25degC） | <=0.30mOhm | 接近模型的 <=0.10mOhm |
| 自谐振频率 SRF | >=3MHz | >=5MHz |
| 绝缘耐压 | 端子对磁芯/安装件 >=100VDC | 更高可以接受 |
| 工作温度 | 至少 -40 至 105degC | -40 至 125degC |
| 导体形式 | 能承受 30A 的宽铜片、扁铜线或多股绞合线 | 低交流电阻扁铜/平面绕组 |
| 磁芯 | 高频铁氧体气隙结构，或经验证的空心结构 | 提供磁芯材料和 300kHz 损耗依据 |
| 资料 | 尺寸图、引脚尺寸、L-I 曲线、温升曲线 | 附样品实测报告 |

`Isat` 和 `Irms` 不是同一个指标：`Isat` 约束直流偏置下的电感下降，`Irms` 约束铜损和磁芯损耗产生的温升。该位置流过的是接近零平均值的 300kHz 双极性 DAB tank 电流，不是普通 Buck 电感的小纹波直流电流。商家只写“大电流 50A”而不提供 300kHz 全交流激励下的温升或损耗资料，不能作为合格依据。

## 3. 本项目为什么采用这些电流指标

模型安全工作域的副边电流核算结果为：

- 300W 连续运行最不利副边 RMS 电流约 `12.38A`。
- 300W 连续运行最不利副边峰值约 `24.08A`。
- 500W 受控短时运行最不利副边 RMS 电流约 `14.10A`。
- 500W 受控短时运行最不利副边峰值约 `21.55A`。

所以采购下限采用 `Irms >=25A`、`Isat >=50A`，给开关尖峰、器件偏差、温升和调试过程留出余量；优选 `Irms >=30A`、`Isat >=60A`。这些额定值并不意味着允许修改软件过流阈值或扩大原工作域。

在采购上限 `DCR=0.30mOhm` 时，仅按 14.10A RMS 计算的直流铜损约为：

```text
Pdc = I^2 * R = 14.10^2 * 0.00030 = 0.060W
```

实际总损耗还包括 300kHz 下的趋肤效应、邻近效应和磁芯损耗，因此必须要求商家提供高频温升依据，并在实板强迫风冷条件下复测。

## 4. 可直接复制给淘宝商家的询价文字

```text
需要定制/购买 DAB 变换器用串联传输电感，不是普通输出滤波电感。
开关频率 300kHz，工作范围 200-350kHz。
需要 0.10uH、0.20uH、0.30uH 各 2 只，公差不超过 +/-10%。
Isat 不低于 50A，要求说明判据为电感量下降不超过 20%，优选 60A。
Irms 不低于 25A，并且是300kHz零平均双极性交流电流条件，温升不超过40degC，优选30A以上。
25degC DCR 不高于0.30mOhm，优选接近0.10mOhm。
SRF 不低于 3MHz，优选 5MHz以上；端子对磁芯/安装件耐压至少 100VDC。
优先扁铜线、平面绕组或低交流损耗气隙铁氧体结构。

```

如果商家无法提供 300kHz 数据，至少先买样品，不要一次批量下单。

## 5. 到货后如何决定最终焊哪一只

### 5.1 测量变压器副边折算漏感

优先方法：把变压器原边用尽可能短、宽的铜片短路，从副边测量漏感。这样读数可直接视为副边折算漏感 `Llk_transformer_sec`。

替代方法：把副边短路，从原边测得 `Llk_pri`，再按 1:2 匝比折算：

```text
Llk_transformer_sec = Llk_pri * (Ns/Np)^2
                    = Llk_pri * 4
```

测量时必须先做夹具开路/短路补偿，连接线要极短，并至少记录 100kHz 测量值；仪器允许时再记录接近 300kHz 的测量值。

### 5.2 计算需要的外接值

```text
Lexternal = 0.50uH - Llk_transformer_sec - Lpcb_sec
```

首板可先把 `Lpcb_sec` 作为待实测的小量处理。装铜排低功率运行后，可根据副边桥方波电压和电流斜率反算实际总传输电感，再选择最接近的外接电感。

| 计算/实测结果 | 安装决策 |
|---|---|
| 需要补偿 <=约 0.05uH | 继续使用铜排，不装电感 |
| 需要补偿约 0.10uH | 安装 0.10uH |
| 需要补偿约 0.20uH | 安装 0.20uH |
| 需要补偿约 0.30uH | 安装 0.30uH |
| 需要补偿 >0.30uH | 暂停满功率测试，复核漏感测量和控制工作域 |

不能通过并联这些小电感来得到更大电流能力；并联会降低总电感。若需要组合电感量，只允许在重新核算和验证后串联，首板优先使用单只器件减小寄生和连接误差。

## 6. PCB 封装和安装要求

- `LTRANSFER_LINK` 位于 `U_ISEC pin2 IN-` 与 `SEC_SW_A` 之间，属于副边高频交流大电流路径。
- 保留可替换铜排的双端机械接口，优先使用大焊盘加 M4/M5 螺柱或可焊铜片，不使用普通 2.54mm 排针。
- 两端焊盘间距按最终样品实物尺寸画自定义封装，同时预留铜排孔位。
- 电感到副边桥臂和变压器的回路必须短、宽、紧凑，避免额外不可控寄生电感。
- 电感下方不要布置 MCU、采样放大器或敏感信号；附近保留电流探头和差分电压探头测试空间。
- 首次样机在 15A RMS 附近强迫风冷运行时，实测电感温升应不高于约 40degC；若超过，应降低工作范围或重新选型。

## 7. 不要和输出滤波电感混淆

本文件说的是 `LTRANSFER_LINK` 的可选 `0.10-0.30uH` 外接传输电感。

输出端还有一只完全不同的必装电感 `LOUT`。最新版模型与首选实物 `Coilcraft SER2915H-222KL` 的参数一致：

```text
电感量：2.20uH，公差 +/-10%
DCR：典型 1.86mOhm，最大 2.05mOhm（25degC）
SRF：典型 40MHz
Isat：100A（电感下降10%、20%和30%的官方额定值均为100A）
Irms：20A 对应温升20degC；30A 对应温升40degC
测试条件：官方电感量在500kHz、0.1Vrms下测量
```

淘宝替代品必须至少满足：`2.2uH +/-10%`、`DCR <=2.05mOhm`、`Isat >=100A`、`Irms >=30A @ 40degC温升`，并能在 300kHz 连续工作。若商家无法提供高频损耗数据，优先直接寻找 `SER2915H-222KL` 原装件。

`LOUT` 不能拿来代替传输漏感，`LTRANSFER_LINK` 的小电感也不能拿来代替 `LOUT`。
