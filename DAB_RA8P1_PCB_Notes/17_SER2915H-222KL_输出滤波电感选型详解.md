# SER2915H-222KL 输出滤波电感选型详解

版本：H1.7-LOUT-R1
日期：2026-07-13
适用模型：`DAB_RA8P1_Final_Physical_MOSFET.slx`

## 1. 先给结论

首板仍建议使用 `Coilcraft SER2915H-222KL`，暂不修改 BOM。

它并不是常见的小型贴片电感。器件本体约为 `27.9mm x 27.9mm x 15.36mm`，质量约 `29.7g`。本项目的最大连续输出电流为 `8.33A`，限定的 500W 短时最大输出电流为 `13.89A`；该器件的官方温升参考电流为 `20A/30A`，分别对应约 `20degC/40degC` 温升，因此直流电流能力有明显余量。

如果确实希望采用体积更大、通孔安装、铜损更低的器件，直插首选应改为新一代 `Vishay IHXL1500VZEB2R2M3A`，不是旧款 `IHXL1500VZEB2R2M51`。新款约为 `38.1mm x 38.1mm x 21.89mm`，最大 DCR 仅 `0.34mOhm`，并使用比上一代降低约 20% 磁芯损耗的新材料，但公差为 `+/-20%`，电流能力远超本项目需求，价格、占板面积、采购和机械应力都会增加。

若完全不计体积、重量和成本，只追求数据手册上的最低 DCR、最大温升电流和最大饱和电流，则纸面参数最强的是 `Vishay IHXL2000VZEB2R2M3A`。它达到约 `50.8mm x 50.8mm x 21.7mm`、`285g`，对本项目并不是系统最优，只是极限参数最强。

## 2. LOUT 在电路中的位置和作用

输出正向功率路径为：

```text
副边全桥
  -> CSEC/CSEC_HF 副边桥局部电容
  -> SEC_LOCAL_P
  -> LOUT 2.2uH
  -> VOUT_LOCAL_P
  -> COUT_HF/COUT 输出电容
  -> FOUT
  -> 输出分流器
  -> JOUT
```

输出负极 `SEC_PGND` 不串第二只输出电感，直接作为输出回流路径。

LOUT 的主要作用有四个：

1. 阻碍副边全桥产生的 300kHz 开关电流直接流入输出端。
2. 与 LOUT 后的 `COUT_HF + COUT` 组成低通滤波网络，降低输出电压纹波。
3. 把副边桥局部的高频脉动电流限制在 `CSEC_HF -> 副边桥 -> CSEC_HF` 的小换流环路内。
4. 限制桥前局部母线与 8mF 输出大电容之间的瞬时均衡电流。

LOUT 不是 DAB 传输电感。DAB 的传输电感由变压器自身折算到副边的 `0.50uH +/-20%` 漏感承担，位于高频交流传能回路中；LOUT 位于整流后的直流输出侧，两者不能互换，也不能把二者数值相加后当成同一个器件。

## 3. 为什么电感量选择 2.2uH

当前仿真和首板输出网络已经冻结为：

| 位置 | 参数 |
|---|---:|
| LOUT 前局部电解 | `94uF`，等效 ESR 约 `56mOhm` |
| LOUT 前高频 MLCC 有效容量 | `40uF` |
| LOUT | `2.2uH`，DCR 按最坏 `2.05mOhm` |
| LOUT 后高频 MLCC 有效容量 | `40uF` |
| LOUT 后大电解 | `8000uF`，等效 ESR 约 `3.875mOhm` |

仅用 `2.2uH` 与 `8000uF` 估算，理想 LC 谐振频率为：

```text
f0 = 1 / (2*pi*sqrt(L*C))
   = 1 / (2*pi*sqrt(2.2uH*8000uF))
   = 约 1.20kHz
```

300kHz 开关频率约为该谐振频率的 250 倍，因此该网络对开关频率分量有很强的理论抑制能力。实际纹波还受电容 ESR、MLCC 直流偏压、PCB 寄生、负载、控制器和电感交流损耗影响，不能只按理想二阶滤波器计算。

`2.2uH` 是滤波能力、瞬态速度和控制稳定性之间的折中：

- 小于 2.2uH：电感电流纹波增大，更多 300kHz 电流进入 COUT，输出纹波和电容纹波电流上升。
- 大于 2.2uH：开关纹波可能进一步下降，但 LC 谐振频率降低，输出瞬态变慢，启动和电压环补偿需要重新设计。
- 改成 4.7uH：理想谐振频率会从约 `1.20kHz` 降到约 `0.82kHz`，不是可直接替换的元件值，必须重新验证控制环、软启动、负载突变和全工况纹波。

因此，选型时首先要保持 `2.2uH`，不能只因为某个更大的电感容易购买就随意改成 3.3uH、4.7uH 或 10uH。

## 4. 项目实际电流和直流铜损

输出电流由 `Iout=Pout/Vout` 得到：

| 工况 | 输出电流 | SER2915H 按最大 DCR 的直流铜损 |
|---|---:|---:|
| 300W / 48V | `6.25A` | `0.080W` |
| 300W / 36V | `8.33A` | `0.142W` |
| 500W / 48V，限定短时 | `10.42A` | `0.222W` |
| 500W / 36V，限定短时 | `13.89A` | `0.395W` |

计算使用：

```text
Pcu_dc = Iout^2 * DCRmax
DCRmax = 2.05mOhm
```

这些只是直流铜损，不包含：

- 300kHz 电流纹波造成的交流铜损。
- 磁芯损耗。
- 邻近效应和集肤效应。
- PCB 焊盘和铜箔损耗。
- 高环境温度导致的铜阻上升。

因此不能根据 `0.395W` 就直接宣布器件温升一定很低。首板必须在真实 PWM、真实风量和最坏允许工况下测量 LOUT 温度。

## 6. “封装小”是否会成为问题

对本项目而言，`SER2915H` 的本体和电流能力并不小。判断是否够用不能只看外观，要看以下比例：

| 比较项 | 比值 |
|---|---:|
| `20A` 温升参考电流 / `13.89A` 最大短时输出 | `1.44` |
| `30A` 温升参考电流 / `13.89A` 最大短时输出 | `2.16` |
| `100A` 的 10% 降感电流 / `13.89A` 最大短时输出 | `7.20` |

实际电感电流包含开关纹波，所以最终应使用“直流分量加纹波峰值”检查 Isat，使用总 RMS 电流检查温升。即便如此，现有额定值仍不是当前设计的紧张项。

真正容易出问题的是 PCB 落地方式：

1. 必须使用 Coilcraft 官方推荐 land pattern，不按器件照片猜焊盘。
2. 两个功率焊盘直接连接宽铜皮，禁止热焊盘细辐条和局部窄颈。
3. 2oz 可作为最低外层铜厚，首板优先 3oz，并让正向功率路径宽度与输出连接器、保险和分流器一致。
4. 官方第三焊盘只用于机械稳定，不得接入功率网络。
5. 器件约 29.7g，焊后增加中性电子硅胶、非导电压片或扎带固定点。
6. LOUT 两端禁止设置铜排、0Ohm 或焊锡旁路，否则会直接失去输出滤波。
7. 在电感本体附近安装绝缘 NTC，首板实测温升；NTC 引线属于控制岛，不得接触功率铜或磁芯。

所以，如果担心的是“焊盘扛不住 14A”，解决方法首先是正确的官方焊盘、厚铜、宽铜和机械加固，不是盲目换成更大的电感量。

## 7. 是否有更大的替代件

### 7.1 直插方案中的最优候选

`Vishay IHXL1500VZEB2R2M3A` 是目前资料完整、名义电感量不变、体积明显更大且核心材料更新的直插首选：

| 参数 | Vishay IHXL1500VZEB2R2M3A | Coilcraft SER2915H-222KL |
|---|---:|---:|
| 安装 | 通孔宽铜引脚 | 表面贴装扁铜端子 |
| 本体尺寸 | 约 `38.1 x 38.1 x 21.89mm` | 约 `27.9 x 27.9 x 15.36mm` |
| 标称电感量 | `2.2uH` | `2.2uH` |
| 公差 | `+/-20%` | `+/-10%` |
| DCR 最大值 | `0.34mOhm` | `2.05mOhm` |
| 40degC 温升参考电流 | `133A` | `30A` |
| 饱和判据 | `104A` 时约降 20%；`150A` 时约降 30% | `100A` 时约降 10%；20%/30% 点均大于 100A |
| SRF | 典型 `15MHz` | 典型 `40MHz` |
| 磁芯/结构 | 新一代金属合金屏蔽结构；比上一代磁芯损耗约低20% | 铁氧体屏蔽扁铜线结构 |
| 300kHz 实物温升 | 仍需测试 | 仍需测试 |

Vishay 方案在最坏 DCR 下的直流铜损约为：

| 工况 | 直流铜损 |
|---|---:|
| 300W / 36V | `0.024W` |
| 500W / 36V，限定短时 | `0.066W` |

它的优点是尺寸更大、通孔机械强度高、DCR 极低、温升和故障电流余量巨大，而且核心材料比上一代 `-51/-5A` 更好。缺点是占板面积约增加 86%，高度增加约 6.5mm，公差变宽到 `+/-20%`，采购成本和供货风险更高，而且对 14A 级输出明显过度设计。

如果采用 Vishay，模型必须至少重新检查 `1.76uH / 2.2uH / 2.64uH` 三个电感角点，验证输出纹波、软启动、负载突变和环路稳定性后才能冻结 PCB。

官方资料：<https://www.vishay.com/docs/34677/ihxl1500vz-3a.pdf>

### 7.2 只看极限参数时的最强候选

若把占板面积、重量、成本和装配全部排除，只比较电流、DCR 和热余量，则 `Vishay IHXL2000VZEB2R2M3A` 更强：

| 参数 | IHXL2000VZEB2R2M3A | IHXL1500VZEB2R2M3A | SER2915H-222KL |
|---|---:|---:|---:|
| 尺寸 | `50.8 x 50.8 x 21.7mm` | `38.1 x 38.1 x 21.89mm` | 约 `27.9 x 27.9 x 15.36mm` |
| 重量 | `285g` | 约 `182g` | `29.7g` |
| DCR 最大 | `0.20mOhm` | `0.34mOhm` | `2.05mOhm` |
| 40degC 温升参考电流 | `154A` | `133A` | `30A` |
| 20% 降感电流 | `190A` | `104A` | 未以20%点给出；10%点为100A |
| 30% 降感电流 | `280A` | `150A` | 大于100A |
| SRF 典型 | `11.3MHz` | `15.0MHz` | `40MHz` |
| 公差 | `+/-20%` | `+/-20%` | `+/-10%` |

2000 系列确实是三者中纸面电流和 DCR 参数最强的，但 285g 的器件需要独立机械承载，不能让 PCB 焊点和通孔承担全部重量。它的额外电流能力对本项目最大 13.89A 输出没有可利用的收益，所以不把它定义为本项目的系统最优。

官方资料：<https://www.vishay.com/docs/34681/ihxl2000vz-3a.pdf>

### 7.3 为什么不把最大器件等同于系统最优

当前没有因为 SER2915H 尺寸导致的电流、饱和或直流铜损不合格项。换成 Vishay 的主要收益是机械尺寸和极低铜损，不会自动改善已经满足目标的输出电压纹波。器件越大还意味着越大的机械载荷、占板面积和功率路径绕行，因此“最大”与“最适合本电路”不是同一个结论。

因此当前决策为：

- 本项目综合最优：继续使用 `SER2915H-222KL`。
- 明确要求通孔、大体积和更低 DCR：使用 `IHXL1500VZEB2R2M3A`。
- 完全不计体积、重量和成本，只追求极限纸面参数：使用 `IHXL2000VZEB2R2M3A`。
- 不建议在一块首板上叠加两套重型电感封装或并联两只电感，这会增加大电流换流面积、焊接错误和机械风险。

## 8. 不能作为等效替代的情况

以下元件不能因为“体积大”就直接替换：

- 只标 `30A`，却没有说明 Isat 降感判据的电感。
- 只给 100kHz 小信号电感量，没有 300kHz 附近损耗或频率曲线的淘宝定制电感。
- DCR 高于约 `2.05mOhm`，却没有重新计算效率和温升的电感。
- 10% 降感电流低于 `40A` 的替代件。
- 40degC 温升参考电流低于 `30A` 的替代件。
- 公差大于 `+/-10%`，却没有对容差上下限重新仿真的电感。
- 3.3uH、4.7uH 等不同电感值。
- 两只普通电感随意串并联拼成 2.2uH。

对定制电感，至少向卖家明确：`2.2uH +/-10%`、测试频率尽量为 `500kHz`、DCR 最大 `2.05mOhm`、10% 降感电流不低于 `40A`、40degC 温升参考电流不低于 `30A`、提供频率曲线或 300kHz 损耗证据，并给出完整尺寸、材料、引脚和固定方式。

## 9. 到货和首板验收

### 9.1 到货前

- 核对完整料号必须是 `SER2915H-222KL`，不能只看“2R2”丝印。
- 索取原厂或授权渠道标签，警惕拆机件、改字件和无批次信息器件。
- PCB 封装必须按最新官方数据手册建立并打印 1:1 纸样核对。

### 9.2 焊接前

- 用四线法测 DCR；普通万用表两线法无法准确测量 2mOhm。
- 用 LCR 表记录 100kHz 和设备允许的更高频率下电感量。
- 检查本体、端子和第三机械焊盘是否与 PCB 一致。

### 9.3 上电后

按 `0W -> 50W -> 100W -> 200W -> 300W` 分级升功率，并记录：

- LOUT 平均电流、RMS 电流和可获得的峰值电流。
- LOUT 两端 300kHz 纹波电压。
- 输出纹波峰峰值。
- 电感本体中心、端子和相邻 PCB 铜皮温度。
- 变压器、MOS、CSEC_HF 和 COUT_HF 温度。

300W 连续阶段必须在规定风量和热稳态下验收。500W 只按 1s、3s、5s 逐级短时测试，不能因为电感额定值很高就把整机 500W 改成连续额定。

## 10. 最终采购建议

本项目首板采购优先级：

1. 首选 `Coilcraft SER2915H-222KL`，与当前仿真、BOM、原理图和 PCB 规范一致。
2. 若只能通过非授权平台购买，先买少量样品做 L、DCR、尺寸和温升验收，再购买正式数量。
3. 若用户明确决定采用更大的通孔器件，则使用新一代 `Vishay IHXL1500VZEB2R2M3A`，不再选旧款 `IHXL1500VZEB2R2M51`，也不与 SER2915H 共用含糊的万能封装。
4. 在完成 Vishay 的 `1.76/2.2/2.64uH` 三角点验证前，不修改正式 BOM。

一句话总结：本项目综合最优仍是 `SER2915H-222KL`；直插最优是 `IHXL1500VZEB2R2M3A`；完全不计尺寸重量时纸面参数最强的是 `IHXL2000VZEB2R2M3A`。
