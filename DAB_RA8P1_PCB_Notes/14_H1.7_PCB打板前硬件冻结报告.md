2. `26_DCDC_BOM_首板硬件定版.csv` 或其 H1.7 Excel 版，作为器件和装配状态最高优先级。
3. `02_四层PCB布局布线与驱动小板规范.md`，作为布局、Kelvin 回路、隔离和铜皮最高优先级。
4. 本报告，作为验证边界和发板准入条件。

## 2. 冻结后的真实功率链

全机只使用 **1 个高频变压器 T1**。功率路径为：

~~~text
JIN
 -> F1/FH1
 -> DTVS_IN
 -> LCM1（输入共模电感，每绕组2mH/30A）
 -> CIN输入储能与高频电容
 -> 原边AONS66917T全桥
 -> TMCS原边高频电流检测
 -> T1（PQ4040/PC95，3:6匝，1:2）
 -> TMCS副边高频电流检测
 -> 副边AONS66917T全桥
 -> CSEC桥侧电容
 -> LOUT 2.2uH
 -> COUT 8000uF及高频电容
 -> FOUT
 -> 输出分流器
 -> DTVS_CONN
 -> JOUT
~~~

必须同时满足：

- T1 的副边折算总漏感固定为 `0.50uH ±20%`，由变压器自身承担。
- PCB 不画外接传输电感、不画相关连接器、不画跳线或 0Ω 配平位。
- 只保留已经定制的输入共模电感 LCM1，不设置旁路铜桥。
- 输出端不使用共模电感，也不预留共模电感或相关旁路。
- LOUT 必装，不允许铜排、0Ω 或焊锡旁路。

## 3. H1.7 最后一次硬件修正

### 3.1 采样侧 5V_SENSE 电源

旧结构把四颗 AMC3302/AMC3330 全部挂在 TLV77333 的 3.3V 输出。按数据手册最坏电流，四颗 AMC 合计约 `162mA`，再叠加 TMCS、UCC 输入侧和逻辑后，SOT-23 LDO 的结温余量不足。

H1.7 改为：

~~~text
5V_CTRL
 -> FB_5V_SENSE（600Ω@100MHz，额定至少500mA，低DCR）
 -> 5V_SENSE
 -> 22uF + 100nF
 -> 四颗AMC的pin12 VDD
 -> TLV77333输入

TLV77333输出3V3_AFE
 -> TMCS、模拟前端、基准和低压逻辑
设计总负载 < 100mA
~~~

计算结果：TLV773 在 `5V -> 3.3V、100mA` 时耗散约 `0.17W`；按局部环境 `60°C` 和数据手册热阻估算结温约 `101.2°C`，低于 `125°C` 上限。四颗 AMC 的 `0.81W` 负载由 5V 隔离辅助电源承担，不再经过 3.3V LDO。

### 3.2 输出电感数据纠正

`SER2915H-222KL` 的官方关键值为：

- `2.2uH ±10%`
- DCR 典型 `1.86mΩ`，最大 `2.05mΩ`
- 10% 降感电流 `40A`
- 20%/30% 降感电流 `100A`
- `20A/30A` 分别对应约 `20°C/40°C` 温升条件

所以不能再写成笼统的“Isat 大于 100A”。本项目 300W 和限定 500W 的直流输出电流低于其温升额定，但 300kHz 纹波损耗和器件附近温度仍必须实测。官方资料：<https://www.coilcraft.com/en-us/products/power/shielded-inductors/high-current-flat-wire/ser/ser29xx/ser2915h-222/>

### 3.3 主开关和栅极网络

真实订货型号为 `AONS66917T`，模型中的 `AONS66917` 只是简称。每只 MOS 固定使用：

- `Rg_on = 4.7Ω`
- `Rg_off = 2.2Ω`
- `Dg = PMEG4010ER`
- `Rgs = 10kΩ`
- `Zgs = BZT52C15`
- 驱动电平约 `0/10.18V`
- 初始死区 `120ns`
- 无 PNP/NPN 加速关断器件和焊盘

模型已包含每管 `LD/LS/LG = 1/1/2nH` 和 UCC21520 输出阻抗。AOS 官方资料：<https://www.aosmd.com/sites/default/files/res/datasheets/AONS66917T.pdf>

## 4. 多轮验证结果

### 4.1 静态冻结审计

`validate_h1p7_hardware_freeze.m` 共检查 68 项，全部通过：

- 变压器 `57.5/230uH`、1:2 匝比和 `0.50uH` 副边漏感未改变。
- 4 条 PCB 母线寄生各为 `5nH`，对应单桥正负母线换流环路约 `10nH`。
- 八路 GateScale、GateBias、开通/关断电阻、下拉、驱动输出阻抗和 RC 吸收一致。
- 八只 MOS 的电气参数与封装寄生一致。
- BOM 为 179 行、10 列，无空位号和重复位号。
- 模型、BOM 和权威文档中无外接传输电感、QFAST、LOUT 旁路或旧锁存器订货号。

### 4.2 精细栅极与 Vds 四工况

`validate_h1p6_gate_fine.m` 使用 `5ns` 最大步长复核 4 个代表工况：

| 指标 | 结果 | 判据 |
|---|---:|---:|
| 稳态 Vgs 高电平 | `10.171–10.174V` | `9.9–10.5V` |
| 关闭管 Miller 抬升最大值 | `0.126V` | `<1V` |
| 关断到 Vgs≤1V 最大时间 | `50ns` | `≤120ns` |
| 上下管同时高于 2V | 未出现 | 必须为零 |
| 已测重复 Vds 峰值 | `47.3–50.0V` | `<80V` |

### 4.3 母线寄生高电流正反例

旧的 0.35ms 扫频在控制器完成软启动前就结束，不能证明满应力余量。H1.7 已把测试改为 `2.6ms`，只分析末 `100us`，并记录真实高频电流。相同测试连续运行两次，结果一致：

| 单桥换流环路 | 原边峰值 | 副边峰值 | 重复 Vds 峰值 | 80V 设计限值 |
|---:|---:|---:|---:|---|
| `5nH` | `69.05A` | `34.62A` | `56.14V` | 通过 |
| `10nH` | `66.04A` | `33.12A` | `60.87V` | **通过** |
| `20nH` | `60.74A` | `30.47A` | `68.81V` | 通过，但不作为 PCB 目标 |
| `40nH` | `52.28A` | `26.25A` | `80.17V` | 失败 |
| `80nH` | `60.71A` | `30.47A` | `113.78V` | 明确失败负对照 |

由此冻结：**每个全桥局部正负母线换流总环路必须做到约 `≤10nH`。** 10nH 工况相对 80V 设计限值保留约 `19.1V`，相对 100V 器件额定保留约 `39.1V`。这一结论依赖局部母线 MLCC、短宽叠层铜皮和每管首装 `10Ω+470pF` RC 吸收，不能用长母线或远端电解电容替代。

本扫频故意产生高于正常软件工作点的 66A 级原边峰值，用于 Vds 应力验证。它没有建模 TMCS 比较器对 `RAW_FAULT_N` 的真实翻转，因此不能解释成“当前 SPS 可以在 66A 下持续工作”。正常软件必须把工作峰值限制在硬件 OC 之前。

### 4.4 联锁五状态

`validate_h1p6_interlocks.m` 全部通过：

- 默认 RUN 关闭时不产生开关动作。
- 正常预充且 RUN/FAULT 有效时允许开关。
- `RAW_FAULT_N=0` 时关闭全部门极。
- 电压越域时即使命令存在也不产生实际门极开关。
- 冷启动只允许受限原边脉冲，副边保持关闭。

### 4.5 冷启动九角点

`Vin = 18/24/28V` 与 `Llk_sec = 0.4/0.5/0.6uH` 共 9 个零伏启动角点全部通过。最坏角点为 `18V、0.4uH`：

- 原边峰值 `32.44A < 35A`
- 副边峰值 `16.19A < 20A`
- 重复 Vds 峰值 `29.99V`
- 副边门极保持关闭
- 无桥臂直通

### 4.6 七种初始输出电压

`0/10/20/30/36/40/42V` 七种初始状态全部通过。0–40V 使用受限启动脉冲，42V 能进入正常 SPS；所有工况的原边峰值不超过 `33.89A`、副边不超过 `16.63A`，未出现上下管重叠。

## 6. 固定磁件下的可用功率域

变压器和输入共模电感不修改。正常 SPS 不能把 `18–32V 输入、36–48V 输出` 当作任意组合矩形。

### 300W 连续目标

~~~text
18V <= Vin <= 28V
36V <= Vout <= 48V
|Vout - 2Vin| <= 8V
Pout <= 300W
~~~

如果必须给出任意组合的矩形范围，只能写 `Vin=20–22V、Vout=36–48V、300W`。

### 500W 短时实验目标

~~~text
21V <= Vin <= 24V
36V <= Vout <= 48V
|Vout - 2Vin| <= 4V
Pout <= 500W
~~~

最坏 `Llk_sec=0.40uH` 的理想分段计算表明，限定 500W 区的原边峰值加预留约 `44.69A`，低于原边硬件 OC 的保守最小值 `58.75A`。因此现有 OCP 硬件不会从物理上阻止合适控制算法实现限定 500W 短测，但当前 SPS 标定尚不能作为 500W 放行依据。

## 7. 明确后置的软件问题

以下问题记录后置，不要求现在改 PCB，但固件阶段必须关闭：

1. 18V 低输入升压侧的正常稳压仍需修正相移方向和增益。
2. 全二维工作域需要 EPS/TPS、PDM 或调频策略来降低比值不匹配时的环流。
3. 48V 平均值误差小于 1mV 需要 ADC 基准、分压器/分流器实物标定、温漂补偿和周期平均，不能由功率电路元件公差天然保证。
4. 软件预警建议先于硬件 OC：连续运行目标 `Ipri_pk<50A、Isec_pk<28A`。
5. 500W 必须按 1s、3s、5s 逐级放行，并同时检查峰值电流、Vds 和热像。

这些待办不会要求改变 T1、LCM1、MOS、驱动器、采样器、保护锁存或输出滤波拓扑，前提是 PCB 完整实现 H1.7 的测量与硬件关断通路。

## 8. 发送 Gerber 前必须关闭的五项

1. **RA8P1 FSP 引脚配置验收**：真实针脚映射已写入编号11第14节；Gerber 前必须让 GPT0-3、GTETRGB/POEG、AN000-AN011、RUN、FAULT 的 FSP 配置无冲突，并逐项核对 `pin_data.c`。
2. **实物封装冻结**：按已购 T1、LCM1、LOUT、TMCS、分流器、保险座、铜柱和连接器实测尺寸建立封装；T1 还要测 Lm、0.40–0.60uH 短路漏感、DCR、耐压和匝间电容。
3. **原理图逐网 ERC**：三地隔离、八路 Gate/Kelvin、四颗 UCC21520、四路隔离门极电源、两路 TMCS OC、锁存/POEG、5V_SENSE 和输出保险必须逐网通过。
4. **PCB 换流环路审查**：每个全桥局部正负母线换流环路目标 `≤10nH`；局部 MLCC 必须直接跨桥，不能经长细颈、连接器或远端母线。
5. **隔离、热和机械复核**：三域无铜带/槽、爬电距离、MOS 热过孔、保险更换空间、29.7g LOUT 机械固定、风道和探头测试点全部落实。

只要这五项在真实 EDA 工程中关闭，本报告对“是否可以发首板 Gerber”的结论才从暂时 NO-GO 转为 GO。

## 9. 首板焊接后的强制验证顺序

1. 不装 MOS，验证 5V_CTRL、5V_SENSE、3V3_AFE、3V3_DRV、四路隔离 5V 和四路 10.18V。
2. 装驱动与单桥 MOS，低压双脉冲验证 Vgs、死区、Miller、Vds 和 RC 吸收温升。
3. 验证 TMCS OC 到 `RAW_FAULT_N -> POEG/DIS -> 锁存` 的真实总延时。
4. 限流电源下验证 0V 冷启动，再验证 10/20/30/36/40/42V 分级进入。
5. 50W、100W、200W、300W 逐级运行并记录所有热点和纹波。
6. 完成 300W 热稳定后，才允许在限定二维工作域做 500W 逐秒短测。

## 10. 最终判断

**可以依据 H1.7 文档集开始完整原理图和 PCB 设计；不能仅依据 Simulink 模型截图直接抄板，也不能在第 8 节未关闭前直接发 Gerber。**

当前唯一已知未闭环项是控制算法在低输入和宽比值范围内的标定，而不是需要返工的功率硬件拓扑。首板是否一次成功仍取决于真实封装、换流环路、隔离、焊接、磁件实测和双脉冲结果；仿真不能代替这些实物验证。
