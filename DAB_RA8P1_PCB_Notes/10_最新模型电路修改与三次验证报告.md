# 最新模型电路修改与三次验证报告

版本：H1.3  
日期：2026-07-11  
目标模型：`DAB_RA8P1_Final_Physical_MOSFET.slx`  
MATLAB：R2024b

## 1. 基准和不可变条件

本轮以用户自行修改并确认的外层模型为唯一基准。修改前已在本地 Git 建立提交 `4bd8f47`，没有用内层旧工程覆盖它。

以下固定磁件参数完全未改：

- 变压器匝数 3:6，匝比 1:2。
- 原边励磁电感 57.5uH，副边励磁电感 230uH。
- 副边折算总传输漏感 0.50uH。
- 原边/副边绕组电阻 0.95mOhm/3.0mOhm。
- 输入共模电感每绕组 2mH、30A、DCR 3.5mOhm，耦合系数 0.9997。

## 2. 落实到电路层面的修改

### 2.1 八只 AONS66917

- 体二极管从“关闭”改为启用。
- 使用按 AONS66917 数据手册体二极管曲线拟合的二维查表模型，而不是理想二极管。
- 反向恢复时间使用 43ns；数据手册 Qrr=208nC 作为实物核对基准。
- Rds(on)、Ciss、Coss、Crss 和 100V 耐压保持器件数据手册对应值。

这项修改很重要。关闭体二极管会掩盖死区续流、反向恢复和换流损耗，不能作为可照着画 PCB 的物理模型。

### 2.2 门极驱动网络

- 模型门极电压由原先不可由当前电源实现的 `-2V/10V` 改为 `0V/10V`。
- `Rg_on=4.7Ohm` 保持。
- `Rg_off` 从 1.2Ohm 改为首板起始值 2.2Ohm。
- `Rgs` 从 100kOhm 改为 10kOhm。
- 每管 RC 吸收从 6.8Ohm+1nF 改为 10Ohm+470pF 的首板调试起始值。

RC 吸收不是量产定值。实板必须用双脉冲波形比较 DNP、330pF、470pF、680pF 与不同电阻，最终以 Vds 峰值、振铃衰减和电阻温升决定。

### 2.3 输出滤波网络

- `LOUT` 前的 CSEC 中频电容改为 2x47uF/100V，合计 94uF，等效最大阻抗按 56mOhm建模。
- 新增独立的 `CSEC_HF_MLCC_Bank`，位于副边全桥与 LOUT 之间，按 8x10uF/100V 在 48V 偏压后的保守有效总容量 40uF建模。
- LOUT 改为 Coilcraft SER2915H-222KL：2.2uH，DCR 最大 2.05mOhm。
- LOUT 后 COUT_HF 改为另一组 8x10uF/100V，48V 下保守有效总容量 40uF。
- 8x1000uF/80V 输出储能保持 8000uF。
- 输出泄放由 100kOhm 改为 2x2.49kOhm 串联，总 4.98kOhm；48V 到 5V 理论约 90s。

桥前 CSEC_HF 与 LOUT 后 COUT_HF 是两组不同的实物电容，模型中也已分开，不是把总容量合并来美化纹波。

## 4. 不能被稳态结果掩盖的限制

- 当前保存模型用于 48V 附近稳态电路验证，输出电容带 48V 初始目标；它不是 0V 冷启动通过证明。
- 8mF 在 48V 储能约 9.22J。实物必须使用输出保险，且软件必须受限软启动。
- 固定 0.50uH 漏感下，`Vout<36V` 时禁止直接运行普通 50% 方波 SPS；需要限峰值电流的 EPS、PDM 或三电平窄脉冲。
- 300W 连续允许域是 `18V<=Vin<=28V`、`36V<=Vout<=48V`、`|Vout-2Vin|<=8V`，不是任意电压组合。
- 仿真通过不等于 Vds 尖峰、磁件温升、输出电感损耗和 300W 热平衡已经实测通过。
