当前唯一仿真基准是外层 `DAB_RA8P1_Final_Physical_MOSFET.slx`。该文件基于用户自行修改后的最新版继续完善；内层同名旧模型不得用于覆盖。

本轮新增：`10_最新模型电路修改与三次验证报告.md`、`11_完整原理图逐器件逐引脚接线表.md` 和 `DAB_RA8P1_首板硬件定版BOM_H1.3.xlsx`。三次 6–10ms 验收窗口均得到平均误差约 -0.718mV、纹波约 0.070961Vpp；固定磁件参数自动断言通过。

## 1. 先给可以直接执行的结论

可以开始画原理图，但只能以本文件和同目录中编号 01、02、03、04、08、09、10、11、26 的新文件为准。连接关系优先级为 11 最高，采购大件以 26 为基础并结合 11 的外围补充。旧文件 25_DCDC_BOM_立创优先.csv、FINAL_SIM_BOM_PARAMS.csv 以及 2026-07-10 之前的说明只能作为历史记录，不能直接照抄下单。

当前硬件主线确定为：

| 项目 | 首板定版 |
|---|---|
| 拓扑 | 双有源全桥 DAB，原副边各 4 只离散 MOSFET |
| 输入/输出 | 硬件接入 18–32V；普通 SPS 额定运行 18–28V；输出 36–48V，且必须满足 `|Vout-2Vin|≤8V` |
| 功率口径 | 300W 连续只在上述二维工作域；500W 仅为 21–24V、`|Vout-2Vin|≤4V` 的受控短时实验目标 |

| 栅极驱动 | 每个半桥 1 颗 UCC21520DWR，共 4 颗 |
| 驱动隔离电源 | 每个半桥 1 颗 UCC33421QDHARQ1，再由 TLV61046ADBVR 升到约 10.18V；反馈锁定 118kΩ/10.0kΩ |
| 快速电流保护 | 原边、次级统一采用 TMCS1133B7AQDVGR；分别用 VOC 电阻设定约 65A/40A 硬件门限 |

这套硬件保留了 TI TIDA-010954 中真正能迁移到 DC-DC DAB 的部分：双桥高频隔离、TMCS1133 快速电流保护、UCC33421 隔离辅助电源、分区布局、硬件关断和分阶段上电。没有照搬其 230VAC 周波变换桥、并网滤波、PLL/PR、MPPT、650V GaN 和 100Hz 能量缓冲。

## 2. 旧版中必须纠正的项目

| 旧项目 | 问题 | 新结论 |
|---|---|---|
| NMK0512SAC | 数据手册只定义为功能绝缘；输出非稳压，轻载会升高，不符合“隔离最好”目标 | 删除，换 UCC33421QDHARQ1 + TLV61046ADBVR |
| TLV3201 直接称为“隔离快速保护” | TLV3201 本身不隔离；旧 BOM 没有给出从功率电流到比较器的完整通路 | 快速通路改为带强化隔离和 OC 输出的 TMCS1133 |
| BZT52C12 | 10–12V 驱动下钳位余量太小，易在正常尖峰中耗散 | 改 BZT52C15，直接跨 MOS 栅源 |
| 栅源 100kΩ | 在高 dv/dt、可拔插驱动板环境下过弱 | 改 10kΩ，每只 MOS 独立放置 |
| 关断电阻 1.2Ω 固定 | 峰值关断电流和负向振铃余量偏激进 | 首装 2.2Ω，预留 1.0/1.5/1.8/2.7Ω 调试值 |
| 自举电容 470nF | 按 AONS66917 最大 Qg=115nC 计算，直流偏压后余量不足 | 改 1µF/25V X7R + 100nF |
| 输出 TVS SMCJ54A | 87.1V 级钳位对 80V 电容和 100V MOS 的余量过小 | 改为桥前 ZBUS_SEC 和接口 DTVS_CONN 两颗 SMCJ48A；硬件过压约 52.01V |
| 输入 TVS SMCJ36A | 对 63V 输入电解的保护余量一般 | 输入严格不超过 32V 时改 SMCJ33A |
| MTP2920-2R2MC | 资料主要给出 100kHz 数据，无法证明 300kHz 纹波损耗 | 首选 Coilcraft SER2915H-222KL；MTP 只作备选并必须实测温升 |
| PSA 22µF/100V MLCC | 缺少易取得的逐料号直流偏压曲线，旧模型把名义容量和有效容量混用 | 主线改为有官方偏压模型的 TDK C5750 系列 |
| 模型栅极 +10/-2V | 与首板单极性约 10V 驱动不一致 | 硬件按 0/10V；仿真随后改为一致 |
| MOS 体二极管关闭 | 不符合 AONS66917 实物 | 仿真随后打开体二极管和恢复效应 |
| 输出电容预充 48V | 冷启动结果不真实 | 后续验证必须从 0V 冷启动 |
| TLV61046 反馈 71.5kΩ/10kΩ | 按 0.795V 基准只能得到约 6.48V，UCC21520 会落在 8V UVLO 以下 | 改为 118kΩ/10.0kΩ，标称约 10.18V |
| 隔离 5V 侧重复 22µF、10V 侧重复 10µF | 可能触发 UCC33421 16ms 启动超时，且超过 TLV61046 总有效输出电容范围 | UCC 输出只保留 15nF+22µF；TLV 输入 1µF+100nF；TLV 输出 2.2µF+100nF，VDDB 4.7µF+100nF |
| URH2405 只靠 SMCJ33A | TVS 最大钳位约 53V，高于模块 40V 最大输入和 50V/1s 浪涌 | F_AUX 后增加 TPS26600，约 35.4V 切断、1.5A 限流 |
| 输出无独立保险 | 8mF 在 48V 储能约 9.22J，输入保险与桥臂 OCP 不能切断其向外部短路放电 | COUT 后增加 PV-15A10-2P，再接输出分流器与 JOUT |

## 3. 三条隔离边界

主板必须被看成三个互不相连的电气岛：

1. PRI_POWER：输入、原边全桥、变压器原边。
2. SEC_POWER：副边全桥、输出滤波、负载端。
3. CTRL_ISLAND：RA8P1、模拟调理、故障锁存、通信控制侧。

CTRL_ISLAND 不得在任何位置直接连接 PRI_PGND 或 SEC_PGND。四块驱动板中，UCC21520 隔离控制脉冲，UCC33421 隔离门极电源；AMC3302/AMC3330/TMCS1133 隔离测量信号。调试电脑通过 RA8P1 USB 接入时，电脑地仍只在 CTRL_ISLAND。

建议在三域之间采用不小于 8mm 的无铜带，并在驱动隔离器、采样隔离器和变压器下方开槽。虽然本机母线低于 60V，这个距离仍按“最佳隔离和抗共模干扰”目标保留。

## 4. 四块驱动小板是否可行

思路可行，但必须改变“普通排针把所有信号都插过去”的理解。

允许的做法：

- 一块小板只驱动一个半桥，高、低侧两只 MOS。
- 四块小板完全同原理图、同 PCB，只改变丝印地址。
- 小板平行贴近主板安装，功率侧连接器到 MOS 栅极和 Kelvin 源总路径小于 10–15mm。
- 控制侧和功率侧使用两个物理分离的连接器，中间保留至少 8mm 隔离槽。
- 控制侧可用普通排针；功率侧首选半孔焊接，其次是低矮板对板连接器，并为每个 Kelvin 源并联至少 2 个返回触点。

禁止的做法：

- 小板竖直插起数厘米。
- GH、GL、SH、SL 共用长单排针。
- 高低侧共用一根细源极返回线。
- 让驱动输出跨越主板长距离后再到 MOS。
- 在小板隔离器下方或两连接器之间铺地、铺电源或放安装螺钉。

因此，四块小板方案可以保留；若无法满足上述机械距离，则把驱动直接集成到主板反而更可靠。

## 5. 采样部分的取舍

为获得最好的隔离、精度和快速保护，采样器件与主功率板一体：

- TMCS1133 必须直接串在变压器电流路径中。
- CSS2H 分流器必须焊在输入和输出直流路径，并使用四线 Kelvin。
- AMC3302 的高压侧 RC 与 HGND 必须紧邻分流器。
- AMC3330 的高压侧分压电阻必须位于各自功率域。
- 只有隔离后的 OUTP/OUTN、VOUT、OC、ALERT 等控制域信号可以进入 CTRL_ISLAND。

把原始毫伏信号或分流器两端通过排针送到小板，会把大电流回路、电磁干扰和接触电阻一起带入测量，禁止采用。

## 6. 在送板前仍必须完成的三个冻结点

“可以画原理图”不等于“现在就可以直接下单 PCB”。送板前必须关闭：

1. 确认比赛提供的 RA8P1 开发板准确型号、连接器和可用 GPT/ADC/POEG 引脚；目前只能冻结网络名，不能臆造物理针脚。
2. 对已定制变压器实测 Lm、短路漏感、DCR、耐压、匝间电容和 300W 温升；结果只用于缩小工作域和降额，不能再改变压器或提高过流门限掩盖偏差。
3. 对最终原理图做一次逐网 ERC，并对 PCB 做一次“八个门极环路、四个半桥换流环路、三条隔离带、所有 Kelvin 线”的人工复核。

## 8. 当前仿真能证明和不能证明的内容

现有模型能说明两个全桥、1:2 变压器和相移传能的基本拓扑方向正确，也帮助给出了电压、电流等级和滤波器初值。

它暂时不能证明首板已经“完美可量产”，因为当前模型仍存在冷启动、预充电、体二极管、门极电压、寄生参数、温升和真实保护链未闭合等问题。后续只做与硬件一致性直接相关的仿真修改；在硬件文档冻结前，不再为点对点控制精度消耗主要工作量。
