# RA8P1控制DAB与硬件保护的统一策略

## 1. 控制边界

硬件负责快速切断和失效安全，MCU负责正常时序、闭环、显示、降额和故障记录。MCU软件尚未实现保护状态机时，不允许绕过新增保护MOS直接运行。

## 2. 状态机

| 状态 | 输出 |
|---|---|
| OFF | RUN_REQ=0，三个保护EN=0，PROT_RESET_N=0 |
| RESET | 三个EN=0，PROT_RESET_N低脉冲后拉高 |
| PRECHARGE | IN_PRECHARGE_EN=1，其余EN=0，等待至少1.5s |
| INPUT_ON | IN_MAIN_EN=1，50µs后关闭预充 |
| OUTPUT_ON | OUT_PROT_EN=1 |
| SOFT_START | RAW_FAULT_N=1时RUN_REQ=1，从最小相移增加 |
| RUN | 电压闭环、限流、温度管理 |
| FAULT | RUN_REQ=0，三个EN=0，保存故障，不自动重试 |

## 3. 正常DAB控制

- Q1～Q8保持固定频率和互补驱动。
- 通过原副边桥之间的相移控制传输功率。
- 上电和恢复时从最小相移软启动。
- 使用ADC_VOUT进行48V闭环，IIN/IOUT/IPRI/ISEC用于限流和诊断。
- 当前硬件无LOUT，软件不得假设存在独立输出LC滤波器。

## 4. 故障优先级

最高优先级：

- RAW_FAULT_N变低。
- 驱动器欠压或DIS_BUS有效。
- TPS48111/TPS48110本地故障锁存。

发生后立即关闭RUN_REQ和三个保护EN，不等待普通控制循环。

其次：

- MCU检测到电压、电流或温度达到软件限制。
- 先减小相移；达到停机阈值时进入FAULT。

## 5. 温度策略

- 显示原边、副边和环境三路温度。
- 同时计算原边/副边相对环境温升。
- 可从70°C预警、80°C降额、90°C受控停机开始调试，但必须由实测重新定标。
- Q18/Q19约150°C动作是灾难性末级保护，不能作为正常控温目标。

## 6. GPIO初始化

P602、P603、P604、PB00配置为3.3V推挽输出，初始化为0。PB06配置为RAW_FAULT_N输入。GPIO复用完成前，Pmod 2和并行图形接口不得连接会驱动这些针脚的设备。

## 7. 故障恢复

只有故障源消失、温度回落、RUN_REQ和三个EN均为0时，才允许人工或受控复位。复位后必须重新执行完整预充流程，禁止自动连续重启。
