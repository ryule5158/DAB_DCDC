# SER2915H-222KL 参数

完整的选型推导、项目电流与损耗计算、PCB 要求以及更大通孔替代件比较，见 `17_SER2915H-222KL_输出滤波电感选型详解.md`。本文件只保留购物车快速核对参数。

| 参数 | 数值 |
|---|---|
| 型号 | `Coilcraft SER2915H-222KL` |
| 标称电感量 | `2.20uH` |
| 公差 | `+/-10%` |
| DCR（25degC） | 典型 `1.86mOhm`，最大 `2.05mOhm` |
| SRF | 典型 `40MHz` |
| Isat | `100A` 对应 10% 降感；20%/30% 降感电流均大于 `100A` |
| Irms | `20A` 对应约 20degC 温升；`30A` 对应约 40degC 温升 |
| 电感量测试条件 | `500kHz`、`0.1Vrms` |
| 项目工作频率 | `300kHz` |
| 绕组形式 | 扁铜线大电流功率电感 |

最终 PCB 中 LOUT 必装，不设置铜排、0Ω或焊锡旁路。`Isat` 必须注明降感判据：本型号 10% 降感点为 `100A`，20%/30% 降感点均大于 `100A`。首板仍必须验收实际 300kHz 纹波温升和机械固定。
