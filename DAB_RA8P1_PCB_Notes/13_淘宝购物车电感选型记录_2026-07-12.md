# SER2915H-222KL 参数

| 参数 | 数值 |
|---|---|
| 型号 | `Coilcraft SER2915H-222KL` |
| 标称电感量 | `2.20uH` |
| 公差 | `+/-10%` |
| DCR（25degC） | 典型 `1.86mOhm`，最大 `2.05mOhm` |
| SRF | 典型 `40MHz` |
| Isat | `40A` 对应 10% 降感；`100A` 对应 20%/30% 降感 |
| Irms | `20A` 对应约 20degC 温升；`30A` 对应约 40degC 温升 |
| 电感量测试条件 | `500kHz`、`0.1Vrms` |
| 项目工作频率 | `300kHz` |
| 绕组形式 | 扁铜线大电流功率电感 |

最终 PCB 中 LOUT 必装，不设置铜排、0Ω或焊锡旁路。`100A` 不能再写成笼统的 10% 饱和电流；首板验收以 10% 降感点 `40A`、实际 300kHz 纹波温升和机械固定为准。
