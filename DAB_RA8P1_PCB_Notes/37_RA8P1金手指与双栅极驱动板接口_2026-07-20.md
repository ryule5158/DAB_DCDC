# RA8P1—主板 CN2—双栅极驱动板接口

> 版本：2026-07-20
> 依据：嘉立创 EDA 工程“瑞萨杯”的当前结构化网表，以及“瑞萨CPKHMI-RA8P1扩展板 (1)”原生网表/PCB `PAD_NET`
> 读取方式：只读 API 和网表，未使用截图判断，未修改或保存原理图/PCB

## 1. 结论

- 已实测的 PWM、ADC、控制、故障、I2C、风扇和 UART 引脚全部保留，不移动。
- 新增 3 个 MCU 输入：`PRI_HW_OK_CTRL`→PB06/P6.18，`SEC_HW_OK_CTRL`→PB01/P6.19，`TEMP_AMB_OT_N`→PB05/P6.20。三针在开发板上连续引出，当前 FSP 均为 Disabled，且可分别用 IRQ0/IRQ12/IRQ15。
- `RAW_FAULT_N1` 和 `RAW_FAULT_N2` 在转接处并联后共同接 P401/P8.8，继续使用 GTETRGA→POEG0 硬件关断。两网都是 BAT54 隔离、4.7 kΩ 上拉到同一 `3V3_DRV` 的低有效故障输出，可安全实现线与；P400/P403 仍分别读取原边/副边过流来判断故障来源。
- 当前 `CAN RS485` 原理图页只有图纸框，无器件、导线或网络，因此本版没有 CAN/RS485 的 MCU 引脚需求。
- 当前主板 CN2 针序已与 2026-07-18 旧文档不同；接线必须以本文的 C5097366 针号为准。

CN2 其余针的网表结论：

- **CN2.51：无网标的悬空线段，必须保持 NC。**
- 除上表 33 个信号/电源针和 CN2.51 外，其余 **86 针全部为 GND**；转接板应使用多点地连接，不要只接一根地线。
- `3V3_RA` 只能用作 3.3 V 电源，不得接到 GPIO。如开发板同时由 USB/J-Link/外部电源供电，先确认两个 3.3 V 轨可并联，否则 CN2.107 保持断开，仅共地。

## 3. 主板到两块栅极驱动板

### 3.1 原边：主板 H5 ↔ 栅极驱动1 H3

两端都是 14 芯，网表针序 1—14 一致，可按同号针制作线束。

| H5/H3 针 | 网络 | 上游 |
|---:|---|---|
| 1 | +12V | 主板驱动电源 |
| 2,4,6,8,10,12,14 | GND | 信号回流 |
| 3 | 3V3_DRV | 驱动逻辑电源 |
| 5 | PWM_PRI_A_H | RA8P1 P415 → CN2.55 |
| 7 | PWM_PRI_A_L | RA8P1 P414 → CN2.57 |
| 9 | PWM_PRI_B_H | RA8P1 P105 → CN2.59 |
| 11 | PWM_PRI_B_L | RA8P1 P104 → CN2.61 |
| 13 | DIS_BUS | CN2.37/RUN_REQ 经 U_GATE_EN 反相后生成 |

### 3.2 副边：主板 H6 ↔ 栅极驱动3 H3/H4

**这不是可直接对插的连接器组合。** 主板 H6 是 14 芯，驱动3 改为两个 10 芯 H3/H4，必须按下表做一分二线束/转接板。

| 主板 H6 | 栅极驱动3 | 网络 |
|---:|---:|---|
| 1 | H3.1 + H4.1 | +12V |
| 2 | H3.2 + H4.2 | GND |
| 3 | H3.3 + H4.3 | 3V3_DRV |
| 4 | H3.4 + H4.4 | GND |
| 5 | H3.5 | PWM_SEC_A_H |
| 6 | H3.6 | GND |
| 7 | H3.7 | PWM_SEC_A_L |
| 8 | H3.8 | GND |
| 9 | H4.5 | PWM_SEC_B_H |
| 10 | H4.6 | GND |
| 11 | H4.7 | PWM_SEC_B_L |
| 12 | H4.8 | GND |
| 13 | H3.9 + H4.9 | DIS_BUS |
| 14 | H3.10 + H4.10 | GND |

`U_GATE_EN` 是 SN74LVC1G10，B/C 固定为高，因此 `DIS_BUS = !RUN_REQ`：上电 RUN_REQ=0 时 DIS_BUS=1，两块 UCC21520 处于禁止状态；只有 RUN_REQ=1 时 DIS_BUS 拉低才允许驱动。

## 5. 开发板本地保留接口

- UART9 继续使用 P208(RX)/P209(TX)，115200-8-N-1，**不经主板金手指 CN2，不得换脚**。
- DAB 状态灯继续使用 P402/P4.1，它是开发板本地调试功能，当前主板 CN2 没有对应网络。
- 新增 PB06/PB01/PB05 只在本文中完成了硬件分配；在业务固件配置前，上电必须把 RUN_REQ 及所有使能默认保持为 0。
