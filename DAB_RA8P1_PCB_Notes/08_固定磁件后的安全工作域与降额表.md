# 固定磁件后的安全工作域与降额表

版本：H1.1
日期：2026-07-11
用途：原理图、PCB、仿真工况和 RA8P1 运行许可的共同边界

## 1. 两个磁件全部锁定

下列参数来自已经定制、已经购买的实物，不允许为了扩大仿真范围而修改：

| 磁件 | 锁定参数 |
|---|---|
| 高频变压器 T1 | PQ4040 / PC95；原副边 3:6 匝；`Np:Ns=1:2`；`Lm_pri≈57.5µH`；`Lm_sec≈230µH`；总副边折算传输漏感标称 `0.50µH`；DCR 上限约 `0.95/3.0mΩ` |
| 输入共模电感 LCM1 | 双绕组；每绕组 `2mH`；额定 `30A`；每绕组 DCR `≤3.5mΩ`；12 匝、2.3mm 线；现有仿真耦合系数 `k=0.9997` |

变压器和共模电感的样品测试只用于确认实物偏差、损耗和温升，并据此缩小软件工作域；测试结果不授权改变上述定制值。板上 `LTRANSFER_LINK` 仍保留为测量、铜排跳线和调试保险接口，首板基线按 `0Ω` 装配，不依靠增加外置电感满足本文件的额定区。

## 2. 为什么旧的矩形范围不能继续使用

把变压器电压统一折算到副边：

~~~text
V1 = 2 × Vin
V2 = Vout
f  = 300 kHz
L  = 0.50 µH（副边折算标称值）
~~~

在 SPS 零相移、零传输功率附近，电压不匹配本身也会产生三角环流：

~~~text
Isec_pk = |2Vin - Vout| / (4fL)
Ipri_pk = 2 × Isec_pk
~~~

例如 `Vin=32V、Vout=36V`：

~~~text
|2Vin - Vout| = |64 - 36| = 28V
Isec_pk = 28 / (4 × 300k × 0.50µ) = 46.7A
Ipri_pk = 93.3A
~~~

这还是没有输出有功功率时的结果，已经超过原边 TMCS1133B7 的标称约 `65.3A` 硬件门限。因此，`18–32V 输入` 和 `36–48V 输出` 不能再写成可以任意组合并正常开桥的矩形额定范围。

## 3. 计算采用的保护余量

现有硬件过流阈值保持不变：

| 通道 | 标称硬件 OC | 计入约 ±10% 门限误差后的保守最小值 |
|---|---:|---:|
| 原边 TMCS1133B7 | 65.3A | 58.8A |
| 副边 TMCS1133B7 | 40.0A | 36.0A |

首板不把硬件 OC 当作工作点。连续运行按原边总峰值不超过约 `50A` 计算，并把 `0.5A` 留给励磁电流、采样误差和未建模小寄生。模型中的 `L_tol=20%`，因此额定边界按最坏 `L=0.40µH` 复核，而不是只按标称 `0.50µH` 给出漂亮数字。

精确 SPS 功率关系采用：

~~~text
P = V1V2/(ωL) × φ × (1 - φ/π),  0≤φ≤π/2
~~~

求得满足目标功率的较小相移根后，对每段线性电感电流取峰值。最坏 `L=0.40µH` 时：

| 条件 | 最坏原边传输电流峰值 | 加 0.5A 后 | 结论 |
|---|---:|---:|---|
| 300W，`|Vout-2Vin|≤8V` | 47.65A | 48.15A | 可作为连续额定准入边界 |
| 500W，`|Vout-2Vin|≤4V` | 44.19A | 44.69A | 仅作为短时实验电气边界 |

这只是理想分段电流加保守漏感容差的结果。实物还必须用 TMCS 波形、差分探头和热像验证开关尖峰、RMS 电流和温升。

## 4. 首板正式运行规格

### 4.1 三层电压定义

1. **硬件接入与测量范围**：`Vin=18–32V`。输入 OVP 约 `34.1V`、输入电容和 100V MOS 的选型不因软件额定区缩小而改变。
2. **正常 SPS 开桥范围**：`Vin=18–28V`、`Vout=36–48V`，并且同时满足本节的二维关系。
3. **禁止正常 SPS 区**：`Vin>28V` 或 `Vout<36V`。`28–32V` 只允许控制器、传感器和保护链上电，不允许普通 50% 方波 SPS 正常传功。

### 4.2 300W 连续额定区

必须同时满足：

~~~text
18V ≤ Vin ≤ 28V
36V ≤ Vout ≤ 48V
|Vout - 2Vin| ≤ 8V
Pout ≤ 300W
~~~

对应整数输入电压表：

| Vin | 300W 连续允许 Vout |
|---:|---:|
| 18V | 36–44V |
| 19V | 36–46V |
| 20V | 36–48V |
| 21V | 36–48V |
| 22V | 36–48V |
| 23V | 38–48V |
| 24V | 40–48V |
| 25V | 42–48V |
| 26V | 44–48V |
| 27V | 46–48V |
| 28V | 48V |
| 29–32V | 禁止普通 SPS 开桥 |

如果比赛说明书必须填写“输入范围和输出范围内任意组合都能 300W”的单一矩形指标，则只能保守填写：

~~~text
Vin = 20–22V
Vout = 36–48V
Pout = 300W continuous
~~~

更宽的 `18–28V` 是上表所示的二维映射区，不是任意组合的矩形范围。

### 4.3 500W 只保留受控短时实验

500W 暂时不得写成首板已验证额定值。考虑固定 30A 共模电感的输入电流和首板热不确定性，实验准入进一步限制为：

~~~text
21V ≤ Vin ≤ 24V
36V ≤ Vout ≤ 48V
|Vout - 2Vin| ≤ 4V
Pout ≤ 500W
~~~

| Vin | 500W 短时实验允许 Vout |
|---:|---:|
| 21V | 38–46V |
| 22V | 40–48V |
| 23V | 42–48V |
| 24V | 44–48V |

持续时间从 `1s`、`3s`、`5s` 逐级增加；必须同时受原边/副边峰值电流、MOS/变压器/共模电感/输出电感温度和 Vds 尖峰限制。没有完整波形与热记录前，不得把 5s 当作承诺值。

## 5. 冷启动不属于正常 SPS 工作域

`Vout=0V` 时天然不满足上述电压匹配关系。输出 8000µF 从 0V 充电时，不能直接让两桥输出普通 50% 占空方波，再仅靠桥间相移慢慢拉升，否则 0.50µH 传输电感上的电流斜率过大。

首版固件必须二选一：

1. 实现受峰值电流约束的三电平、EPS 或 PDM 窄脉冲启动；启动阶段建议 `Ipri_pk≤35A、Isec_pk≤20A`，进入 `Vout≥36V` 后才切换到正常 SPS 状态。
2. 若第一版测试固件暂时只有 SPS，则只允许在外部预充、限流电源和示波器监视下验证正常稳态；这种测试不能被记录为“0V 冷启动通过”。

PCB 不需要为改变变压器而重画，但必须保留两个高频电流测量通道、硬件 OC、POEG 关断和输出电压检测，否则无法安全完成真实冷启动。

## 6. RA8P1 软件许可和迟滞

推荐用滤波后的实测量判断，不用命令值代替实测值：

~~~text
进入 NORMAL_SPS：18≤Vin≤28，36≤Vout≤48，|Vout-2Vin|≤7.5V
保持 NORMAL_SPS：18≤Vin≤28，36≤Vout≤48，|Vout-2Vin|<8.0V
越界：立即停止增加功率；持续越界则 RUN_REQ=0 并进入受控停机
连续预警/降额：Ipri_pk≥45A 或 Isec_pk≥24A
软件绝对限制：Ipri_pk≥50A 或 Isec_pk≥28A
硬件 OC：保持约 65.3A / 40.0A，不提高
~~~

电压入口用 `7.5V`、退出用 `8.0V` 是为了给 ADC 噪声和控制动态留迟滞。真实固件还应要求连续若干次有效 ADC 样本后才能改变状态，并把任何 `RAW_FAULT_N` 交给 POEG 第一拍关断。

## 7. PCB 与测试直接结论

- 变压器焊盘、匝比、绕组参数和共模电感焊盘全部按已购实物画，不改值。
- 输入连接器、保险丝、铜皮仍按至少 40A 瞬时能力设计；共模电感本体固定 30A，因此 500W 只能短时并必须测温。
- `Vin=30V/32V` 时，36–48V 输出域内不允许普通 SPS 正常开桥；这应由 RA8P1 状态机和硬件 RUN 许可共同体现，而不是靠操作人员记忆。
- 首次样机实测总副边折算传输电感若小于 `0.40µH`，只能进一步缩小工作域或降功率，不能提高过流门限掩盖问题。
- 原理图上将本文件的二维准入条件写在 MCU/保护页旁边；PCB 丝印至少标注 `SPS RUN: VIN 18-28V, |VOUT-2VIN|<=8V`。
