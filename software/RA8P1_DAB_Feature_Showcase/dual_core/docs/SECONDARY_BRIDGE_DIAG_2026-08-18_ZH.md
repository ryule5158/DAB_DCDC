# RA8P1 DAB 副边桥无功率诊断流程

适用固件：`2026-08-18-dualcore-secondary-diag-v47d`

本流程只用于定位 Q5～Q8、隔离器、UCC21520及PWM时序，不验证功率传输。测试期间不得执行 `on`。

## 1. 必须满足的物理条件

1. 优先断开主输入与电子负载；若外部保留低压设置，必须确认板卡PRE/MAIN/OUT功率路径均关闭。
2. 确认板内DAB输出母线低于2 V、各电流接近0 A。
3. 只保留控制板和门极驱动所需的辅助供电。
5. 高边VGS必须使用隔离或差分探头，探头参考端接对应MOS源极。禁止把接地示波器探头地夹接到高边源极或桥臂中点。

固件会检查板载VOUT、电流以及PRE/MAIN/OUT/RUN/PWM状态。当前板载VIN通道在功率路径关闭时仍可能显示约18 V，因此不能用它单独判断板内母线是否带电。每次脉冲测试前发送一次`diagarm isolated`；它只在确认所有功率路径和PWM均关闭后生效，15秒内只允许绕过VIN采样一次，执行一条诊断命令后立即失效。VOUT、电流、ADC、PWM和功率路径检查不会被绕过。

## 2. 先确认P008采样链

依次发送：

```text
version
off
adccheck
```

`adccheck`在PWM和全部功率路径关闭后，对P007、P008、P009各采集32组DMA值与ADC结果寄存器直读值。

- P008的DMA和DIRECT都应接近万用表测得的约1.65 V。
- DIRECT约1.65 V而DMA明显不同：优先检查DMA取帧或缓存。
- DMA和DIRECT都明显偏离万用表：优先检查ADC引脚映射、模拟模式及实际测点。
- P008正确后才能使用IOUT工程值；本流程本身不依赖IOUT闭环。

## 3. 单管静态门极检查

每条命令只把对应MCU PWM输入置高100 ms，其他七路保持低，随后自动全部关闭：

```text
diagarm isolated
gate q5
diagarm isolated
gate q6
diagarm isolated
gate q7
diagarm isolated
gate q8
```

每次分别检查UCC21520输入端和对应MOS的VGS：

- 被选通通道应出现稳定的正常门极高电平；其余通道必须保持低。
- 命令结束后所有VGS必须返回低电平。
- 任一路UCC输入正确但VGS异常，检查该路隔离驱动、驱动供电、栅极电阻、焊点及MOS栅源是否异常。

## 4. 两个副边半桥分别检查

```text
diagarm isolated
seca 100
diagarm isolated
secb 100
```

`seca 100`只输出Q5/Q6互补PWM，Q7/Q8和原边保持低。固件MCU引脚自检的预期值为：

```text
expected_HI=0x30 LO=0xFF RUN/MOVE=0x0F/0x0F
```

`secb 100`只输出Q7/Q8互补PWM，其预期值为：

```text
expected_HI=0xC0 LO=0xFF RUN/MOVE=0x0F/0x0F
```

示波器应确认：频率约299.76 kHz、同一半桥上下管互补、门极实际死区存在、没有上下管同时为高、脉冲结束后全部关闭。配置死区为400 ns，最终以VGS实测为准。

## 5. 副边整桥检查

```text
diagarm isolated
sec 100
```

Q5～Q8运行100 ms，Q1～Q4保持低。MCU引脚自检预期：

```text
expected_HI=0xF0 LO=0xFF RUN/MOVE=0x0F/0x0F
```

除两个半桥各自互补外，SEC_A与SEC_B应相差半个开关周期，使副边桥形成正负交替方波。任一桥臂不翻转、长期保持同一电平或边沿明显错位，都不能进入带母线测试。

## 6. 零相移八路对齐检查

只有前五项全部通过后才发送：

```text
diagarm isolated
pwmtest 100
```

该命令让Q1～Q8按SPS零相移、内移相0/0 ns运行100 ms，功率路径仍保持关闭并自动超时停止。比较以下波形：

- PRI_A与SEC_A应同相。
- PRI_B与SEC_B应同相。
- 每侧A、B桥臂应相差半个周期。
- 四个半桥都必须保持上下管互补和实际死区。

若MCU引脚诊断通过，而MOS VGS或桥臂关系不满足上述条件，问题位于MCU引脚之后；不要通过修改相移极性掩盖硬件波形故障。

## 7. 结果判定

| 观察结果 | 优先检查位置 |
|---|---|
| `[SEC-DIAG][MCU] FAIL` | GPT、PFS复用、MCU引脚或诊断选择逻辑 |
| MCU自检通过，UCC输入异常 | 控制板到隔离器/驱动器的连接与隔离器 |
| UCC输入正确，单路VGS异常 | UCC21520通道、驱动供电、栅极电阻、焊点、MOS栅源 |
| 单管正常，半桥互补或死区异常 | 驱动传播、上下管通道、栅极回路及测量参考 |
| 两个副边半桥正常，八路零相移不同步 | 原副边定时关系、隔离链传播或实际引脚接线 |
| 无功率波形全部正常 | 保存波形后再设计低电压、限流、短时母线测试，不直接恢复18 V功率测试 |

任意阶段出现异常，先保存四通道波形并停止在该阶段，不继续执行后续命令。
